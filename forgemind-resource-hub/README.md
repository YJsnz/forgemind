# ForgeMind Resource Hub

ForgeMind Resource Hub（ForgeHub）是面向工业数字资产的本地资源库与 Web CAD 工作台。项目将设备、零件、材料、参数、建模历史和工程属性组织为可保存、可恢复、可继续编辑的资源对象，并可以把结果交给 ForgeMind 数字工厂使用。推荐从 ForgeMind 门户 `/forgehub` 进入：点击 ForgeHub 后先显示 ForgePass 身份页，登录成功才进入独立工作台；ForgeHub 所有路由随后继续通过 `/api/auth/me` 复核。

子项目自带 13 个 GLB，统一位于 `public/models/`，全部可在工作台“外观参考模型”下拉列表选择，并随生产构建复制到 `dist/client/models/`。它们是只读外观参考，不是可直接改写的 OCCT B-Rep。

## 主要功能

- 工业资源库：浏览设备、材料和产品资源，进入自由建模、精细展示或装配工作台。
- 高精度资源缓存：八类内置设备/产品按需生成稳定 ID 的 feature-driven CadDocument；内存原型深拷贝，浏览器只保存设计数据，旧版内置 B-Rep/组合文档自动清理而不影响用户项目。
- 参数化建模：用户可绘制任意线段、圆弧和 B-Spline/NURBS 轮廓，并逐项选择草图中的材料区域；拉伸、旋转、实体放样和实体扫掠均可新建、添加、切除或相交，配合孔、圆角、倒角、抽壳、阵列和直接编辑构造独立零件。
- 特征历史管理：搜索与状态筛选、直接及完整上下游追踪、重命名、依赖安全排序、级联抑制/恢复、节点回退和级联删除；所有修改都会先重建验证，并可通过撤销恢复。
- 草图精修：修剪、延伸、偏移、镜像、线性阵列、模型直线/圆/圆弧/NURBS 边投影、开放与封闭 B-Spline、精确 NURBS 次数/节点/权重、首尾切向控制，以及水平、垂直、固定、重合、平行、垂直、相切、同心、相等和中点约束。
- 截面建模：基准草图可以直接修改所在位置，也可以按指定间距复制为下一截面；修改任一截面会自动重建关联的实体放样或扫掠。
- 高级曲面：B-Spline/NURBS、曲面片、拉伸、旋转、扫掠、放样、精确交线、互切分片、缝合、裁剪、偏移、加厚；支持多边界控制网求解、局部软选择、控制线编辑、自然延伸和曲面质量诊断。
- 精确数据交换：STEP 导入与导出、ForgeMind CAD 项目包导入与导出；导入后可按恢复队列重建孔、孔阵列、圆角、倒角、凸台和凹槽。
- 装配工作台：组件实例、固定、重合、距离、同心、角度、转动和滑动配合，以及自由度求解。
- 装配工程检查：自动识别悬空连接组、未配合组件、重复配合、隐藏组件引用和求解异常；提供零件明细（BOM）、组件复制/替换/隔离、求解位置固化及带配合级联删除。
- 本地建模 Agent：把日常中文中的用途、外形、接口和尺寸整理成零件级建模程序，用与手动工作台相同的草图、旋转、放样、扫掠、添加和切除特征生成可编辑 B-Rep；基础体模板只用于快速草模与复杂设备的组件布局。
- 参数化机械细节：螺纹、直齿轮、滚动轴承和线缆路径以独立工程参数生成，不再使用圆环、方块等装饰体模拟；可在特征历史中修改并重新生成。
- 工程就绪检查：用容易理解的语言检查 B-Rep 重建、错误特征、材料、公差、工艺、齿轮根切风险、线缆弯曲半径、轴承滚动体空间和超长螺纹，并给出可执行的修改建议。
- 工程数据：材料、密度、公差、制造工艺、体积、表面积和质量估算。
- 本地项目：工作项目切换、自动保存、历史撤销/重做和跨会话恢复。
- 电脑快捷键：支持保存、撤销/重做、命令搜索、标准视图，以及特征历史查找、选择、重命名、抑制、排序、回退和安全删除。

## Windows 一键启动

直接双击项目根目录中的 `START_FORGEMIND.bat`。启动文件会检查 Node.js、安装缺少的依赖并启动本地服务；启动阶段不会执行 lint 或完整测试，因此不会因检查项阻断开发服务器。

也可以在 PowerShell 中运行：

```powershell
cd D:\Code\factory\forgemind-resource-hub
.\START_FORGEMIND_DEV.ps1
```

批处理文件也支持只检查环境：

```text
START_FORGEMIND.bat --check
```

只检查启动环境、不启动服务：

```powershell
.\START_FORGEMIND_DEV.ps1 -Check
```

不自动打开浏览器或指定端口：

```powershell
.\START_FORGEMIND_DEV.ps1 -NoBrowser -Port 3001
```

直接进入 CAD Part Studio：

```powershell
.\START_FORGEMIND_DEV.ps1 -Entry cad -NoBrowser
```

需要清理构建缓存并验证项目时运行：

```powershell
.\VERIFY_AND_BUILD_WINDOWS.ps1 -Clean
```

验证脚本会严格执行 lint、生产构建和完整回归；完整回归已经包含资源库与综合演示模型检查，不会重复构建。使用 `-SkipFullTest` 时仍会执行资源与演示模型专项测试。任一步失败都会停止并保留原始错误信息，清理缓存只有显式添加 `-Clean` 才会执行。

## 推荐演示流程

1. 从资源库选择“自适应精密装配与检测中心 / DEMO-CAD-05”。
2. 进入自由建模，展示工作项目切换和初始斜上方视角。
3. 展示 64 个可见成品零件、7 个真实 B-Rep 一体结构件和 213 项历史，以及输送、机器人、回转夹具、检测、工具和 NURBS 安全门。
4. 在历史中展开一体式焊接机架或主轴波纹防护套，查看构造体经过实体并集成为单个可交付零件；再编辑孔阵列、减重槽、实体扫掠和五截面机械臂放样。
5. 编辑 NURBS 控制网，使用斑马纹、曲率热力和曲率梳检查表面质量。
6. 展示特征历史管理、STEP 交换、导入特征恢复和本地建模 Agent。
7. 运行工程就绪检查，保存并导出 ForgeMind CAD 项目包。
8. 进入装配工作台，使用 7 个模块演示连接器、配合、自由度、限位、BOM 和项目恢复。
9. 返回资源库，完成资源—建模—装配—复用闭环。

完整讲解顺序见 `ForgeMind_完整功能演示操作流程.txt`，项目原理与当前边界见 `ForgeMind_项目功能与技术逻辑说明.txt`。

## 综合演示模型

`DEMO-CAD-05` 是一套由真实 CAD 数据生成的自适应精密装配与检测中心，而不是静态展示网格。它包含 91 个实体/曲面体、64 个可见成品零件、86 个草图、213 项可编辑历史和 7 个装配模块。机架、输送底架、夹具导向底板、夹爪壳体、检测门架、工具架和主轴波纹防护套由多个构造体经过真实 B-Rep 并集形成独立零件；机器人上下臂改为可编辑的五截面光顺放样。模型同时覆盖孔切除、线性/圆周阵列、旋转、实体扫掠、实体放样、NURBS 加厚与偏移、螺纹、齿轮、轴承、线缆、工程属性和装配求解。27 个构造体或工艺参考体保留在历史中但不重复显示，原有精细 GLB 设备资产也继续保留。

## 建模数据逻辑

`CadDocument` 保存草图、特征顺序、实体、材料和持久拓扑引用。OCCT/WASM 根据设计历史重建真实 B-Rep；Three.js 只负责显示、选择、旋转、缩放和剖切。保存项目时不保存临时网格或内核句柄，重新打开后会根据设计数据完整重建。

手动建模与 Agent 建模共用同一套数据结构和重建器。手动模式中，用户可以自由绘制非矩形或曲线轮廓，并依次建立实体拉伸、旋转、扫掠、放样、添加和切除；Agent 只是根据自然语言自动生成同样的草图和特征顺序，因此结果可以在特征树中继续修改，而不是不可编辑的几何体组合。

STEP 导入的实体会作为带来源资产的特征进入项目。对面和边的后续操作使用持久拓扑引用，降低模型重建后选择对象失效的概率。恢复队列会合并阵列成员孔，并在每次提交后重新分析最新 B-Rep，避免重复恢复或使用旧拓扑。

## 当前边界

- B-Spline 曲面支持完整张量积 NURBS：U/V 可分别设置次数、节点与重数，每个控制点具有独立权重；数据进入特征历史并随项目保存恢复。
- 完整 NURBS 模式的 U/V 加密采用有理齐次坐标节点插入，增加控制线时保持原曲面形状；普通控制网模式仍保留用于主动改变外形的中点加密。
- B-Spline 控制网可同时关联多条相邻曲面边界。求解时会锁定位置、切向或曲率控制带并只光顺自由内部点；标准控制网/完整 NURBS 提交后会沿每条关联边取 11 个真实 B-Rep 采样点检查接缝、法向和主曲率，未达到目标不会进入历史。旧项目中的单向有理截面仍可重建并保留边界关系，但由于其截面方向不等同于稳定的 OCCT UV 参数方向，会明确跳过这项参数连续性检查。任意裁剪曲面和任意支撑面的主动 G1/G2 求解仍受当前 WebAssembly 内核接口限制。
- 开放 B-Spline 可作为曲面扫掠路径并约束端点切向；封闭拟合 B-Spline 或精确加权 NURBS 会重建为原生 OCCT 曲线，可直接用于实体拉伸、切除、旋转和放样。
- 一个草图可以包含多个独立材料区域、内孔以及孔内岛；创建实体特征时可以选择参与成形的区域。对称拉伸使用总长度均分到基准面两侧，双向拉伸则分别保存正向和反向距离。
- 拉伸、旋转、扫掠与放样共用实体运算层：同一个特征可以创建新实体，也可以对所选实体执行添加、切除或相交；多区域和带内孔轮廓会先生成精确工具体，再按历史中的目标特征完成布尔运算。
- 模型直线、圆、圆弧以及 B-Spline/NURBS 边可作为带持久拓扑来源的精确外部草图参考；NURBS 引用保留次数、节点、重数、控制点、权重和实际裁剪参数范围。两个曲面可生成保留在特征历史中的精确 B-Rep 交线，交线可选择并继续作为边界或草图投影来源。提交草图前会按当前 B-Rep 自动刷新投影，引用丢失或无法唯一定位时会阻止提交并保留上一次正确模型。
- B-Spline 曲面选中后可在视口直接拖动控制点，控制网会同步更新，手柄大小会随视距保持可操作；Shift 锁定主轴、Ctrl 按 0.5 mm 吸附、Esc 取消本次拖动。编辑器还提供软选择、整条 U/V 控制线移动、自然边界延伸和内部控制线简化；控制线数量变化时会明确提示节点和权重将重建。
- 开放平滑放样可通过起点和终点的方向引导或曲率趋势增加辅助截面。系统会检查控制长度、方向和两端重叠，并禁止与直纹或闭合放样混用；这用于控制放样形状，不等同于对任意支撑面的数学 G1/G2 保证。
- 曲面偏移和加厚在失败时会依次收紧/放宽内核容差并修复输入面的连接，再以原设计尺寸重试；不会通过暗改距离或厚度换取成功。抽壳还会在修复后重新匹配需要移除的面。
- 当前 `occt-wasm` 的可变半径圆角绑定会影响后续曲面重建，工作台已暂时关闭该操作。恒定圆角、倒角和 NURBS 曲面过渡可正常使用；真可变半径圆角需要稳定的内核绑定后再开放。
- Agent 生成的紧固件采用完整杆长与有效牙长分离：保证装配包络准确，同时避免对重复螺栓无意义地生成过长螺旋面。轴承作为一个机械部件保留内圈、外圈和滚动体多个闭合实体；导出 STEP 时仍作为同一 Body 交付。
- 相同参数的机械细节由 CAD 内核复用不可变母体，每个 Body 获得独立副本和位置特征；这不会改变精度、实体身份或保存数据，但可明显减少设备模型中重复螺栓、轴承和齿轮的生成时间。缓存只存在于当前运行环境，关闭内核时会完整释放。
- 曲面质量检查采用修剪域内的 9×9 面采样和 11 点沿边采样，可报告曲率范围、鞍形/可展候选以及 G0/G1/G2 分布。
- 建模视窗提供斑马纹反射检查、带符号的曲率热力采样点和沿边曲率梳；显示层只负责表达，曲率、法向与连续性等级仍由 OCCT B-Rep 计算。
- STEP 特征恢复采取保守策略，只在几何证据充分时重构孔、圆角、倒角、凸台、凹槽和阵列。
- 质量是根据 B-Rep 体积和材料密度计算的工程估算，不替代实物称重或正式制造验证。
- 项目以本地使用为主，暂不包含多人云协同和完整 PDM 审批流程。
