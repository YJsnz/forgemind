ForgeMind / ForgeHub 项目功能与技术逻辑说明
版本：2026-09-05

一、项目定位

ForgeHub 是 ForgeMind 的工业数字资产入口。它把设备、零件、材料、尺寸、工艺和设计历史组织成可以继续使用的工程资源，而不是只保存一个用于观看的三维文件。

项目主流程：
资源库 → 参数化建模 → 工程检查 → STEP/项目包交付 → 装配验证 → 保存与复用。

ForgeHub 负责资产的创建、整理和流转；ForgeMind 数字工厂可以继续使用这些设备与工程数据完成布局、仿真和运行展示。


二、当前主要功能

1. 工业资源库

- 浏览、搜索和筛选设备、材料与产品。
- 将资源加入建模清单，并进入自由建模、精细模型展示或装配工作台。
- 导入、导出 ForgeMind 资源包。
- 保留资源编号、来源、工程属性和建模定义。
- 从工作台返回时真正回到资源库。

2. 自由建模工作台

- 使用草图、尺寸和约束定义二维轮廓。
- 用户可自由绘制线段、圆弧和 B-Spline/NURBS 轮廓；一个草图可以包含多个材料区域、内孔和孔内岛，并可逐项选择参与成形的区域。
- 拉伸、旋转、多截面放样和路径扫掠统一支持新建实体、向当前实体添加、从当前实体切除或保留相交部分。拉伸还支持正向、反向、对称以及两侧不同距离。
- 同一零件可以连续加入多个特征，不需要把方块、圆柱等基础体堆叠成最终外形。
- 支持推拉、偏移、删除面、去孔与去特征等直接编辑。
- 支持多实体、实体显示控制、材料、公差、工艺、体积、面积和质量估算。
- 支持标准视图、斜上方等轴视图、适合窗口、连续旋转、平移、缩放、剖切和测量。
- 中央视口保持固定，左右侧栏单独滚动。

3. 草图与特征历史

- 草图工具包含线段、矩形、圆、圆弧、点和 B-Spline/NURBS。
- 草图处理包含修剪、延伸、偏移、镜像、线性阵列和模型边投影。
- 基准草图可修改所在平面位置，并可按间距复制为新的放样截面；截面位置与轮廓都属于可继续修改的设计数据。
- 约束包含水平、垂直、重合、平行、垂直相交、相切、同心、相等、中点和固定。
- 特征历史支持搜索、上下游查看、重命名、依赖安全排序、抑制、恢复、回退、级联删除及撤销/重做。
- 参数修改后只重建受影响的特征链；失败时保留上一次正确几何。

4. 高级曲面

- 支持张量积 B-Spline/NURBS 曲面和独立控制点权重。
- 支持曲面片、曲面拉伸、旋转、扫掠、放样、交线、修剪、分割、缝合、偏移和加厚。
- B-Spline 控制网可同时关联多条相邻边界，主动锁定位置、切向或曲率控制带，并光顺自由内部区域。
- 提交关联曲面前，系统会沿每条关联边读取 11 个真实 B-Rep 采样点，检查接缝、法向和主曲率；不满足目标时不写入特征历史。
- 支持控制网直接拖动、软选择、整条 U/V 控制线移动、自然边界延伸、局部控制线简化、轴向锁定、尺寸吸附和取消操作。
- 平滑开放放样支持起点和终点的方向引导与曲率趋势辅助截面；系统会检查长度、方向和重叠，并禁止与直纹或闭合放样混用。
- 支持斑马纹、曲率热力采样和曲率梳，用于判断表面是否顺滑。

5. 精细机械结构

- 外螺纹按大径、螺距、总长、有效牙长和牙深生成真实螺旋表面。
- 直齿轮按模数、齿数、压力角、齿宽和轴孔生成渐开线齿廓。
- 轴承由内圈、外圈和滚动体构成。
- 线缆按空间控制点进行光顺扫掠。
- 相同参数的重复零件复用内核母体，但每个实体仍拥有独立身份和位置特征。

6. STEP 与导入特征恢复

- STEP 导入后保留精确 B-Rep，不以显示网格代替工程几何。
- 系统可识别并恢复孔、沉孔、沉头孔、孔阵列、圆角、倒角、凸台和凹槽。
- 恢复过程按队列逐项执行，每次提交后重新分析最新几何，避免使用已经失效的面或边。
- 证据不足时保留导入实体，不会为了生成历史而猜测特征。

7. 本地建模 Agent

- 用户可以用日常中文说明用途、大概尺寸和结构要求。
- Agent 会补全单位、识别设备类型、区分必要信息与推断信息，并生成可检查的建模计划。
- Agent 会把用途、外形、安装方式和接口要求转换成零件级特征程序，根据需要选择非矩形轮廓、连续旋转轮廓、多截面放样、路径扫掠、添加和切除。
- Agent 与手动工作台共用同一套草图、特征历史和 B-Rep 重建器；生成结果可以继续编辑草图尺寸与特征顺序，不是一次性图片，也不是基础几何体堆叠。
- 适合新手先获得结构合理的初版，再用工作台精修。

8. 装配工作台

- Part Definition 表示可复用零件定义；Component 表示装配中的零件实例。
- 支持固定、重合、同心、距离、角度、转动和滑动配合。
- Mate Connector 保存零件上的连接坐标系，可进行吸附、翻转、角度调整和版本化修改。
- 求解器计算组件位置、剩余自由度和残差；冲突时保留上一次正确位置。
- 支持组件复制、替换、重命名、隔离、隐藏、安全删除和带配合删除。
- 支持装配保存、导入导出、撤销重做、工程检查与 BOM 导出。

9. 工程就绪检查

- 检查 B-Rep 是否完整重建、特征历史是否可编辑、工程资料是否齐全、项目是否可保存和导出。
- 检查齿轮根切风险、轴承滚动体空间、线缆弯曲半径、螺纹计算量和重复标准件。
- 检查结果用中文说明“问题在哪里、可能造成什么影响、建议如何修改”。
- 该检查用于设计预检，不替代正式工程图、强度分析、装配干涉和制造工艺验证。


三、核心数据与运行逻辑

1. CadDocument

保存草图、特征、特征顺序、实体、材料、公差、工艺和资源来源，是项目保存与恢复的主要对象。

2. Feature Graph

特征通过依赖关系形成有向图。修改上游尺寸后，系统传播“需要重建”状态，并按正确顺序重新计算下游特征。

3. B-Rep 与 OCCT

OpenCascade WebAssembly 负责生成精确的面、边、顶点和实体。几何运算、尺寸、面积、体积、STEP 和拓扑选择均以 B-Rep 为准。

4. Three.js 显示层

B-Rep 被三角化后交给 Three.js 显示。Three.js 负责画面、选择、相机和交互，但显示网格不是保存和制造的几何来源。

5. 持久拓扑

后续特征不会只记住临时的面序号，而是保存形状、位置、面积比例、邻接关系等特征。模型重建后，解析器根据这些信息重新找到目标面或边。

6. Last-Good 机制

如果新参数导致特征失败，系统报告具体错误，并保留最近一次成功的 B-Rep，避免整个项目消失。

7. AssemblyDocument

装配文档只保存零件定义引用、组件实例、初始位置、配合和连接器。求解位置属于运行结果，重新打开项目时可根据设计数据再次计算。

8. 本地持久化

项目保存设计数据，不保存 OCCT 句柄、Three.js Mesh 等临时对象。重启浏览器后由保存数据重建几何，避免把运行时状态误当作工程文件。


四、新综合演示设备

名称：自适应精密装配与检测中心
编号：DEMO-CAD-05
外形范围：约 1160 × 860 × 760 mm

该模型包含 91 个实体或曲面体、64 个可见成品零件、86 个草图和 213 项可编辑历史，分为 7 个装配模块。另有 27 个构造体或工艺参考体保留在特征历史中，不会与成品零件重复显示。

1. 基准机架：底座、立柱和横梁通过 B-Rep 并集形成一体式焊接机架，背板与减振脚保留为可拆零件。
2. 精密输送模块：输送基座和导轨形成一体底架，包含真实减重槽线性阵列、滚筒、驱动轴、轴承、同步齿轮、定位托盘和挡停机构。
3. 伺服回转夹具：电机、真实轴承、渐开线齿轮、编码器、主轴、工作台、8 孔圆周阵列、定位锥、双夹爪和四颗真实螺纹紧固件。
4. 六轴精密装配机器人：底座、腰座、肩部、五截面光顺上臂、肘部、五截面轻量化前臂、腕部、两指夹爪、检修盖螺钉和空间扫掠线缆。
5. 视觉与接触检测模块：检测架、工业相机、放样镜头罩、远心镜头、环形光源、激光传感器和接触测头。
6. 工装与控制模块：操作箱、工具架、齿轮、轴承、锥柄刀具、实体扫掠工艺管道和一体式波纹防护套。
7. NURBS 安全门：4×4 控制网母面、12 mm 装配间隙偏移检查面、4 mm 加厚实体和把手组件。

模型覆盖草图、拉伸、口袋切除、线性与圆周阵列、旋转、跨实体 B-Rep 并集、实体扫掠、多截面放样、实体变换、NURBS、曲面偏移与加厚、真实螺纹、齿轮、轴承、线缆、多实体、工程属性和装配拆分。七个一体结构件保留完整构造历史，能够修改任一上游形体并重新生成最终零件。基础零件还能继续用于圆角、倒角、抽壳、直接编辑和 STEP 演示。

装配工作台使用同一份模型数据自动建立七个 Part Definition。机架、供料、检测、工装和安全门保持安装位置；回转夹具与机器人保留为可操作模块，便于现场建立配合、连接器和运动限位。


五、常用快捷键

Ctrl+S：保存项目
Ctrl+Z / Ctrl+Y：撤销 / 重做
Ctrl+K：搜索命令
Ctrl+Shift+F：搜索特征历史
F：适合窗口

Esc：取消当前预览或拖动


六、当前工程边界

- 标准 B-Spline 控制网/完整 NURBS 之间可以主动求解并沿真实 B-Rep 边界检查连续性；旧项目中的单向有理截面仍可重建并保留边界关系，但因截面方向不对应稳定的 OCCT UV 参数方向，会明确跳过该项参数连续性检查。任意复杂裁剪边界、任意支撑面的自动 G1/G2 形状优化仍受当前 WebAssembly 内核接口限制。
- 实体圆角当前以恒定半径为主。浏览器内核提供的可变半径圆角会影响后续曲面重建，因此工作台已暂时关闭该入口；真正稳定的连续变化半径圆角需要后续升级内核绑定。
- 放样的方向引导与曲率趋势通过辅助截面控制形状，不能替代工程曲面中针对任意支撑面的严格 G1/G2 约束。
- STEP 特征恢复采取保守策略，无法证明的特征不会自动猜测。
- Agent 已能生成特征驱动的零件与结构完整的参数化设备初版；当前自然语言解释仍采用本地规则，未明确的关键制造尺寸仍应由工程人员确认。
- 质量和工程就绪结果用于设计阶段参考，不替代强度、碰撞、公差链和正式制造验证。
- 项目目前以本地单机使用为主，尚未包含多人实时协同和完整 PDM 审批。
