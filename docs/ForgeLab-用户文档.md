# ForgeLab 用户文档

> 版本：2026-09-02 · 适用 ForgeLab 社区当前实现

## 1. 模块定位

ForgeLab 是 Forge 生态的开放工厂社区，用于阅读和分享工厂存档、模型资源、布局经验、设计经验和设计者公告。它与 ForgeMind、ForgeCloud 共用 ForgePass 账户。

## 2. 登录和浏览

1. 从官网顶部导航、页脚或 ForgeCloud 入口进入 ForgeLab。
2. 未登录时进入 ForgePass；已有工作台会话可以直接通过身份校验。
3. 在社区首页使用关键词搜索或板块筛选。
4. 点击帖子卡片进入独立文章页，查看正文、作者、统计、相关帖子和附件。

## 3. 五个板块

| 板块 | 适合发布的内容 |
| --- | --- |
| 工厂存档开源 | 楼层、设备、仓储、配方和可复现运行结果 |
| 模型资源开源 | GLB、JSON、原点、包围盒、端口和许可证 |
| 布局经验分享 | 网格规划、通道、坡道、避障和维护空间 |
| 设计经验分享 | 目标、约束、取舍和验证过程 |
| 设计者公告 | 版本变化、社区规则和资源治理说明 |

## 4. 发布帖子

点击首屏“发布帖子”，依次填写板块、标题、摘要和正文；可以附加图片、工厂存档或资源包。正文建议写清楚 ForgeMind 版本、存档版本、复现条件、已知限制和资源许可证。

AI 润色提示词只用于整理表达，发布前必须人工检查事实、版本、来源和附件内容。帖子与附件在后端可用时写入 ForgeLab 数据库；网络不可用时只保留当前会话草稿并明确提示，不会伪装成已公开内容。

## 5. 回复、点赞和通知

文章页支持帖子点赞、回复、回复点赞和跳转现场讨论。通知中心会显示回复、点赞和社区事件，可以单条或全部标记已读。回复尽量包含可复现的操作、证据和版本，不要只留下无法检查的结论。

## 6. 附件和许可

附件下载会经过当前账户权限检查。下载或复用模型、存档和资源包前，先确认作者声明、许可证、来源和是否允许商业使用。社区帖子不是对资产许可的自动授权。

## 7. 工厂助手

右侧 ForgeLab 工厂助手默认使用确定性规则回答发布、许可、布局和设计问题；启用可选 AI 后只能改善解释，不会替代 ForgeMind 的碰撞、寻路、库存和仿真结论。
