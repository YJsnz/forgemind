# ForgeCore 项目协作约定

## 权威项目方案

- 仓库根目录的 `ForgeCore 项目方案.md` 是本项目唯一、持续维护的权威方案文件。
- 凡涉及项目方案、产品范围、功能设计、系统架构、技术选型、数据模型、UI、开发阶段、路线图或项目愿景的新增、删除和调整，必须先读取并直接修改该文件。
- 除非用户明确要求，不要新建平行的“新版方案”“补充方案”或其他替代方案文件；应把变更合并回 `ForgeCore 项目方案.md`。
- 项目正式名称固定为 `ForgeCore`。修改后应检索旧名称和相互矛盾的描述，确保方案内命名及相关章节同步一致。
- 外部目录中的原始文档仅作为导入来源，不是后续维护入口。

## 3D 资产约定

- ForgeCore 原创、可重现的 first-party 资产位于 `assets/3d/core/`；第三方原包位于 `assets/3d/vendor/`；对第三方资产的优化、改材质或语义化版本位于 `assets/3d/derived/`。三者不得混用。
- 首版默认物品模型库位于 `assets/3d/core/items/v1/`，包含 36 个稳定 `modelId`。其权威索引为 `catalog.json`，完整性清单为 `SHA256SUMS`，生成器位于 `tools/item-models/`。
- `core/items` 只允许收录 ForgeCore 原创或项目已明确拥有权利的内容，不得复制、改造或隐性派生于第三方网格、纹理或预览图。当前 v1 不含第三方网格/纹理，且其根目录尚无独立许可文件；未正式确定并记录项目许可前，不得将它们对外宣称为 CC0、CC BY 或其他开放许可资产。
- 修改默认物品的几何、参数 schema、材质、预览或生成逻辑时，必须通过 `node tools/item-models/build.mjs` 重生成，不手工编辑生成的 GLB、PNG、`catalog.json` 或 `SHA256SUMS`；然后执行 `node tools/item-models/validate.mjs`，并同步更新 `ForgeCore 项目方案.md`、`assets/3d/ASSET_AUDIT.md` 和下方协作审计。
- 默认物品运行时契约为自包含 GLB 2.0、米制、Y-up 和 ground-center；`Mass` 与 `Stack Size` 是 Item 业务属性，不得定义为几何或材质参数。
- ForgeCore 的第三方基础模型包括 `assets/3d/vendor/kenney-factory-kit-3.0/`、`assets/3d/vendor/mastjie-low-poly-warehouse-kit/`、`assets/3d/vendor/cels-industrial-agv-trolley/` 与 `assets/3d/vendor/count-infinity-futuristic-delivery-drone/`，版本、许可证、文件清单及导入验证记录见 `assets/3d/ASSET_AUDIT.md`。
- Web 3D 场景优先使用 GLB：Kenney 套件从 `Models/GLB format/` 选用，mastjie 仓储套件从 `glb/` 选用。初版编辑器可按需加载 Cels AGV 与 Count Infinity 无人机 vendor GLB 作为视觉层，其中 AGV 只选择主体子树并排除展示地板；AGV 的尺度目标、碰撞、安全包络、导航、载荷、库存和任务语义必须来自 ForgeCore 独立业务数据，不得从 vendor 网格推断。Cels vendor 外观仍为 `derived pending`，无人机仍为 `simulation planned`；正式批量实例与完整运输仿真继续优先加载审计通过的 `assets/3d/derived/` 版本。`FBX` 和 `OBJ` 仅作为交换格式与兼容性备份。
- Cels AGV 采用 CC BY 4.0，使用及派生时必须保留作品名、作者 Cels、Sketchfab 原模型链接、CC BY 4.0 链接和修改声明；不得误记为 CC0。
- Count Infinity Futuristic Delivery Drone 采用 CC BY 4.0，使用及派生时必须保留作品名、作者 Count Infinity 与作者主页、Sketchfab 原模型链接、CC BY 4.0 链接和修改声明；不得误记为 ForgeCore 原创或 CC0。
- 无人机 vendor 原件不得覆盖、改名或直接声明为正式运行时资产。derived 版本必须记录源文件与 SHA-256，完成尺度、Y-up/+Z 前向、飞行枢轴、贴图优化、LOD、简化碰撞体、导航安全包络、货物挂点、动画来源及语义节点审计；业务载荷、速度、电池和任务规则不得从网格推断。
- `vendor` 下的上游套件应保持原始目录和文件名，不直接覆盖、改名或删除。需要优化、改材质或制作派生模型时，放到 `assets/3d/derived/`，并记录来源关系。
- 新增或升级第三方资产时，必须同步更新 `ForgeCore 项目方案.md`、`assets/3d/ASSET_AUDIT.md` 和下方协作审计。
