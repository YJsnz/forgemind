## 2. 全片唯一空间逻辑

### 工厂尺度硬约束

- 全片工厂必须是**大型三层智能制造厂房**，只允许 L1、L2、L3 三层。
- 三层属于同一座连续建筑，每层都要有高层高、长主通道、多个设备岛、长输送线和远端缓存区。
- 镜头必须表现出大面积地面网格、设备之间的真实间距和远端消失点，不能只拍成几台设备组成的小房间。
- 禁止地下层、夹层、第四层、独立小实验室、局促车间、展柜式工厂和单设备白盒空间。
- 由于 H3 Lite 当前工作流按 640×352 输出，空间“大”主要通过镜头高度、长通道、重复设备组、远端灯带和深透视表现，不靠强行提高分辨率。

### A-01 / LIVE LINE

- **L1：** 原料货架、AGV 装卸通道、线边缓存、无人机停靠位。
- **L2：** 机加工与清洗、钢板冲压、铜线绕制、紧固件齐套，四个制造岛由西向东排列。
- **L3：** 四路输入支线、机器人装配、视觉质检、包装、成品缓存、隔离缓存。
- **物流方向：** 原料从西侧和下层进入，零件向东侧和上层汇合，成品从东侧离开。
- **不可改变：** 楼层高度、设备相对位置、输送带方向、主角物料颜色和尺寸。

### A-02 / AI LAB

- 只在第 7 段出现。
- 是空白网格实验空间，不与 A-01 混用设备位置。
- 负责表现需求解析、Recipe Graph、候选布局、碰撞校验、副本仿真和方案比较。
- 真实文字、数据、候选卡片由 UI 录屏或后期合成，H3 Lite 只生成空间和抽象节点。

## 3. 统一镜头与生成规范

每个镜头生成前必须填写并确认以下字段：

1. **空间：** A-01 或 A-02、楼层、镜头起点和终点。
2. **锚点：** 至少三个必须持续存在的设备或结构。
3. **主体：** 主角物料、AGV、无人机、机械臂或相机臂。
4. **动作顺序：** 用“先、然后、最后”描述，禁止同时发生冲突动作。
5. **镜头运动：** 方向、速度、机位高度、结束构图。
6. **物理限制：** 不穿模、不复制、不瞬移、不倒流、不漂浮。
7. **文字限制：** 不生成 Logo、字幕、数字、中文、英文和可读 UI。

生成模型只负责：

- 工厂空间、设备外观、机械运动、物料运动、灯光和镜头运动。

后期或真实录屏负责：

- Logo、字体、中文、英文、指标、Recipe Graph 标签、候选方案卡片、状态文字和最终数据。

## 6. 每段动作验收标准

### S01 / 工厂先醒来

- 必须是同一座三层厂房。
- 镜头必须从高层向 L1 下降，不能横向穿墙。
- 最终必须停在 L1 原料架前。
- 必须出现唯一主角物料：银灰色金属壳体毛坯。

### S02 / 原料进入系统

- AGV 动作顺序：接近 → 托起 → 转向 → 行驶 → 放下。
- 托盘数量不能突然增加或减少。
- AGV 不能穿过货架、输送线或其他设备。
- 主角物料必须进入输送线，不能瞬移到 L2。

### S03 / 四个制造岛

- 四个工序必须按固定顺序出现。
- 主角物料只进入机加工单元；其他支线作为背景并行运行。
- 每个制造岛都要有输入、设备、输出和缓存。
- 不拍成四台孤立的产品展示图。

### S04 / 跨层汇合

- 无人机必须通过升降井进入 L3。
- 四条输入支线必须从不同方向汇入同一个机器人装配单元。
- 机器人必须完成一次有先后顺序的抓取和放置。
- 不表现为机器人炫技或战斗动作。

### S05 / 视觉质检

- 相机臂必须绕固定零件扫描。
- 合格件进入包装，异常件进入隔离缓存。
- 扫描线不能穿透零件，不能表现为武器激光。
- PASS/FAIL 文字必须后期合成。

### S06 / 背压

- 末端缓存先满，前方物料先停，后方物料依次减速。
- 装配机停在出料状态，而不是直接断电或爆炸。
- 黄色警示沿物流链向上游传播。
- 不使用大面积红光和灾难式警报。

### S07 / AI 实验空间

- A-02 必须是空白网格，不要复用 A-01 的设备布局。
- 生成顺序：需求 → Recipe Graph → 设备估算 → 端口路由 → 碰撞检查 → 三个候选方案。
- 三个候选方案必须有明显策略差异：保守调整、高吞吐、低能耗。
- 不让视频模型生成复杂可读 UI。

### S08 / 决策回到工厂

- 必须回到 A-01，而不是停在抽象 AI 空间。
- 语音助手只播报一到两句状态。
- 应用调整后，缓存压力下降，物流重新运行。
- Logo 最后出现并保留至少 2 秒停帧。

## 7. 旁白定稿

### 主旁白

中文普通话，中性偏低沉，冷静、可靠、克制、清晰；语速 0.95 倍；不要广告腔、不要喊叫、不要模仿具体影视或游戏角色。

### 全文

> 一座工厂真正开始生产之前，先要确认的，不是它看起来像不像工厂，而是每一件物料能不能走到该去的地方。
>
> 在 ForgeMind 里，仓储不是背景。库存、运输、缓存和在途物料，都是产线能否持续运行的一部分。
>
> 一件成品，往往不是从一台机器里直接出现。它来自多条节拍不同、方向不同、却必须最终汇合的生产支线。
>
> 当物料跨越楼层，工厂就不再只是设备的集合。它变成一张包含输送带、AGV、无人机和缓存的生产网络。
>
> 质量不是最后一张报表。它发生在每一次扫描、每一次判断，以及每一次放行或隔离之中。
>
> 真实的产线不会永远顺畅。堵塞、等待和背压，会沿着物流方向反向暴露真正的瓶颈。
>
> ForgeMind 不只告诉你哪里出了问题，还可以把需求变成方案，把方案放进副本里重新运行，再比较哪一种改变真正有效。
>
> 先运行，才能看见问题；看见问题，才有资格做决定。ForgeMind，让工厂先在数字世界里运行。

## 11. 第一轮生成验收门槛

第一轮不追求最终画质，先检查四件事：

1. **空间：** L1、L2、L3 是否能被看懂，楼层和设备是否稳定。
2. **因果：** 物料是否按正确方向移动，背压是否先从下游发生。
3. **连续：** 主角物料、物流方向和镜头运动是否能接起来。
4. **可剪：** 每段结尾是否留下足够的后期合成安全区。

若四项全部通过，再进入第二轮画质、材质、灯光和音乐优化。
