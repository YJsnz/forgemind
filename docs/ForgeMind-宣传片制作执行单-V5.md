# ForgeMind 宣传片制作执行单 V5

关联剧本：[ForgeMind-宣传片剧本-V5-功能闭环版.md](ForgeMind-宣传片剧本-V5-功能闭环版.md)

## 一、统一生成原则

这版不要求每个生成片段首帧和尾帧像素级一致，但必须保持“空间锚点一致”：楼层高度、设备相对位置、物流方向、主角物料颜色和镜头运动方向不能跳变。

每个提示词必须明确：

1. 当前楼层和空间位置；
2. 画面中必须持续存在的三个锚点；
3. 主体动作的先后顺序；
4. 镜头运动方向和结束构图；
5. 物料不能穿模、不能复制、不能瞬移；
6. 不生成 Logo、字幕、数字和可读 UI。

## 二、空间分组

| 空间组 | 对应段落 | 固定锚点 | 生成策略 |
|---|---|---|---|
| A-01 / L1 | 01–02 | 原料架、AGV 通道、升降井 | 连续下降和跟拍 |
| A-01 / L2 | 03 | 四个制造岛、独立缓存、东西向物流 | 横向平移 |
| A-01 / L3 | 04–06 | 四路输入、机器人装配、质检与缓存 | 由高位进入，再沿物流反向追踪 |
| A-02 / AI LAB | 07 | 空白网格、候选布局、诊断面板 | 使用真实 UI 录屏，模型只做背景镜头 |
| A-01 / 回到生产 | 08 | 三层厂房、黄色物流线、Logo 安全区 | 从局部拉升到总览 |

## 三、真实项目素材优先级

1. A-01 三层工厂、生产控制台、诊断界面、视觉检测工作台优先使用真实录屏。
2. H3 Lite 负责补充真实录屏缺少的空间过渡、机械细节、灯光和物料跟拍。
3. 关键 UI、Logo、数字、配方节点、候选指标统一后期合成。
4. 不让 H3 Lite 生成复杂中文；生成画面中的文字一律视为占位。

## 四、建议后期节奏

- 01–02：低频启动，建立空间和物料主角。
- 03–04：节奏加快，表现四路零件和跨层物流。
- 05：短暂放慢，让质量分流清楚可见。
- 06：音乐收紧，突出背压和瓶颈。
- 07：数据节点和候选方案快速生成，但保持工程化秩序。
- 08：回到真实工厂运行，用空间总览和 Logo 完成收束。

## 六、旁白与声音

主旁白保持低沉、中性、克制、工程化；不要模仿具体影视或游戏角色。智能管家单独使用另一种本地授权音色，只播报一到两句真实状态。

音效优先使用项目自有音频、CC0 或明确商用授权素材。网络上能听到的影视、游戏、主播声音不能直接截取使用；如使用网络配音或音色，必须确认本人授权和平台商业使用许可。
