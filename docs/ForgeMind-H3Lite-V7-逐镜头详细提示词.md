# ForgeMind H3Lite V7：逐镜头详细提示词执行包

> **用途：** 为《ForgeMind 宣传片剧本 V7：工厂还没建成之前》提供可直接复制给本地 MiniMax H3Lite 的视频提示词。
>
> **重要原则：** H3Lite 负责生成“空间、设备、动作”和可选的非语言背景音；不负责理解产品功能，不负责生成可读 UI，不负责生成 Logo、字幕、数字或产品名称。旁白、对白和 BT 人声全部在后期单独配制，不能交给视频模型生成。

## 1. 使用规则

### 1.1 生成方式

- 每个 Prompt 单独生成一条视频，不把多个主要动作塞在一个 Prompt 里。
- 每条视频只保留一个主要动作；复杂段落用剪辑拼接，不要求模型自己完成复杂转场。
- 建议每条 5–8 秒、16:9、24fps；优先保证动作连贯，再做放大和调色。
- 第一轮先生成 01、03、04、05、06，确认工厂空间、机械臂、AGV、无人机的外观稳定后，再生成分岔和回滚镜头。
- 同一批次使用相近随机种子，但不能把随机种子当成空间锁定；每条 Prompt 都必须重复写明空间锚点。
- 如工作流支持首帧/尾帧：下一条镜头使用上一条合格镜头的最后一帧作为首帧参考；如不支持，则使用下面的固定空间描述重建。
- 如模型一次只能接受一段短提示词，保留顺序：**主体 → 空间 → 动作顺序 → 镜头 → 风格 → 禁止项**，不要删除动作顺序。

### 1.2 声音生成边界

视频模型可以为每条素材生成与画面同步的非语言声音，但必须把声音当作“氛围底稿”，不能当作最终旁白：

- **允许：** 低频电影氛围、纸张翻页、网格启动声、机械臂伺服声、AGV 轮胎滚动声、无人机旋翼声、继电器/电机轻响、漫画冲击音、版本回退的反向滑动音、克制的无歌词电子配乐。
- **禁止：** 旁白、对白、BT 说话、人声、歌词、可识别单词、播报内容、电话声、会议声、口型与语音同步。
- **混音方式：** 模型声音只作为低音量背景层；旁白后期单独录制，真实 UI 操作音和品牌片尾音效后期统一替换或覆盖。
- **提示词写法：** 每条画面 Prompt 末尾追加对应的 `Audio:` 行；如果 H3Lite 当前工作流不支持音频生成，则保留这些声音描述供后期音效师使用，不影响画面生成。

### 3.1 旁白与声音的后期流程

1. 先导出 H3Lite 画面和可用的非语言背景音。
2. 用真实录屏重新录制 UI 操作音、按钮确认音、Agent 状态音和 Logo 墙音效。
3. 按第 6 节旁白全文单独录制中文旁白；旁白不写入 H3Lite Prompt，也不要求模型生成说话人物。
4. 剪辑时先锁定画面节奏，再把旁白铺在时间线上；模型生成的背景音只做氛围底层，不能盖住旁白。
5. 出现任何可识别人声、英文单词、歌词或疑似模型自动播报时，优先静音该段并用后期音效替换。

## 5. 生成后逐条验收

### 空间连续性

- A-01 必须始终是三层，不得出现第四层或地下层。
- L1 在底部、L2 在中间、L3 在顶部；中央升降井位置不能改变。
- 左侧白色 CNC 加工中心、右侧黑色滚筒输送线、远处三根青绿色灯柱是固定锚点。
- 机械臂始终在 L3 装配站；AGV 只在楼层网格地面行驶；无人机只做跨层运输。

### 动作连续性

- 机械臂必须“抓取 → 搬运 → 放置 → 松开”，不能瞬移或同时抓取多个部件。
- AGV 必须“出发 → 转向 → 绕开障碍 → 到站 → 停止”，不能穿过机器。
- 无人机必须“L1 起飞 → 进入升降井/高位通道 → 经过 L2 → L3 到站”，不能穿透楼板。
- 回滚必须是“选中版本 → 出现复核警示 → 沿时间线退回 → 有效物流恢复”，不能把工厂炸毁后重建。

### 功能表达

- 看到的是智能化设计证据，不是泛泛的机器人炫技。
- 至少一个候选必须被边界、端口、碰撞或导航规则明确拦截。
- 三个候选必须来自同一份 A-01 结构，只改变物流组织或局部取舍。
- Agent 只作为分析、解释、提出受控变更和回滚的流程，不表现为直接控制真实设备。
- 片尾五个产品 Logo 的文字和职责字幕全部使用真实品牌素材和后期排版。

### 失败素材处理

- 出现物体融化、设备漂浮、楼层变形、AGV 飞行、无人机变汽车、机械臂穿模时，整条废弃，不用后期遮盖。
- 出现模型自行生成的文字、数字、Logo、UI 时，整条废弃；不要依赖模糊或裁切补救。
- 出现多个主要动作混在一起时，整条废弃，拆成更短镜头重新生成。
- 出现空间锚点改变时，优先重写 Prompt 的前两段，不要只修改风格词。
