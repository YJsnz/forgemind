# ForgeMind 宣传片剧本 V3

## 片名

**《先让工厂运行起来》**

## 核心创意

> 一条还没存在的产线，先在数字世界里跑一遍。

## 成片定位

- **品牌：** ForgeMind
- **产品：** AI 驱动的智能工厂数字孪生设计、生产路线与仿真平台
- **建议时长：** 90 秒
- **受众：** 制造业客户、技术合作方、投资人、开发者
- **整体气质：** 工业软件宣传片 × 近未来任务简报
- **品牌主张：** 让工厂先在数字世界里运行

## 分镜脚本

### 00:00–00:06｜问题

**画面**

黑屏。机械声、液压锁止声。A-01 数字基地从黑暗中逐层亮起。

**屏幕文字**

```text
A-01 / FACTORY INITIALIZING
PRODUCTION LINE: NOT READY
```

**旁白**

> 一座工厂真正启动之前，还有多少问题，必须先被看见？

### 00:06–00:14｜进入 ForgeMind

**画面**

白色气密舱门开启。镜头穿过舱门，现实工业空间转化为三维数字工厂。

**参考素材**

- `/public/photos/3.png`
- `/public/textures/login/forgemind-airlock-v2.png`
- `/public/textures/login/elevator-shaft-loop-v1.png`

**旁白**

> ForgeMind，AI 驱动的智能工厂数字孪生平台。这里，工厂先于现实开始运行。

### 00:14–00:24｜从需求到方案

**画面**

操作员输入自然语言需求：

```text
生成一条电机装配产线，
要求包含加工、装配、质检与仓储。
```

A-02 Generative Factory 生成 Recipe Graph、设备配置和物流路线。

**屏幕文字**

```text
RECIPE GRAPH
EQUIPMENT ESTIMATE
PORT ROUTING
COLLISION CHECK
WHAT-IF SIMULATION
```

**旁白**

> 从一句生产需求开始，生成工艺、设备、端口和物流路线。每一个方案，都要经过验证，才值得被采用。

### 00:24–00:35｜搭建与校验

**画面**

进入工建模式。设备沿网格放置，传送带自动延伸，设备旋转 90 度。

**状态文字**

```text
VALID PLACEMENT
FLOW CONNECTED
COLLISION DETECTED
```

**参考素材**

- `/public/photos/1.png`
- `/public/photos/2.png`
- `/public/images/equipment/forgemind-equipment-atlas-v1.png`

**旁白**

> 设备放在哪里，物料向哪里流，不是凭感觉，而是在落地之前完成一次检查。

### 00:35–00:48｜仿真启动

**画面**

点击“启动”。原料从 Source 出发，沿传送带移动，进入加工中心，再进入装配单元。

**屏幕文字**

```text
LOGICAL TIME 00:12.4
ITEM LOTS IN TRANSIT 06
MACHINE STATUS PROCESSING
CONVEYOR STATUS FLOWING
```

**旁白**

> 当仿真启动，静态设备变成生产系统。每件物料都有位置，每台机器都有状态，每条线路都有节拍。

### 00:48–00:58｜问题不会被隐藏

**画面**

下游缓存被占满。物流逐段减速，上游设备停止。镜头沿物流链反向追踪，定位到瓶颈设备。操作员增加缓存后重新运行，物流恢复。

**屏幕文字**

```text
OUTPUT BLOCKED
BACKPRESSURE DETECTED
```

**旁白**

> 真正的数字孪生，不会只展示顺畅的动画。堵塞、等待、背压和恢复，都必须被看见。

### 00:58–01:08｜一座工厂是一个系统

**画面**

Panda 机械臂抓取零件；AGV 携带托盘驶入缓存区；无人机通过升降井完成跨层补给；L1、L2、L3 多楼层同时亮起。

**旁白**

> 机器人负责动作，AGV 负责流转，仓储负责缓冲。多楼层、多设备、多条路线，在同一张生产网络中协同运行。

### 01:08–01:16｜视觉质检

**画面**

相机臂环绕零件扫描。扫描线扫过表面，异常件进入隔离路线。

**屏幕文字**

```text
VISION INSPECTION
360° SCAN
PASS / FAIL
```

**旁白**

> 质量不是最后一张报表。它发生在每一次扫描、每一次判断、每一次放行之中。

### 01:16–01:24｜本地智能管家

**画面**

操作员按下语音按钮，AI 状态依次变化：`LISTENING`、`ANALYZING`、`SPEAKING`。本地智能管家读取当前工厂状态。

**本地模型播报**

> 当前产线运行稳定。检测站已完成质检。加工单元出口缓存负载较高，建议优先检查。

**旁白**

> 不只是看见工厂，还可以向工厂提问。

### 01:24–01:30｜从观察到决策与片尾

**画面**

总览、生产、诊断三个视角快速切换。瓶颈、物流方向、设备状态被同一套数据重新解释。

**旁白**

> 先看见变化，再理解原因，最后决定下一步。

**画面**

总览、生产、诊断三个视角快速切换，随后所有物流线收束为 ForgeMind 黄色斜线。片尾使用原始 Logo 后期叠加，不交给视频模型重绘。

**屏幕文字**

```text
FORGEMIND
SMART MANUFACTURING PLATFORM
```

**旁白**

> 先看见变化，再理解原因，最后决定下一步。ForgeMind，让工厂先在数字世界里运行。
