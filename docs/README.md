## 维护规则

- 新功能先更新根方案，再更新事实总览和对应专题。
- 当前代码与文档冲突时，先以代码复现结果为准，再修正文档。
- 资产来源、许可证、文件替换或生成器变化必须进入资产审计。
- 历史文档中的路径、端口和模型策略可能已经失效，引用时必须注明“历史”。
