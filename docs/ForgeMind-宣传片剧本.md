# ForgeMind 宣传片剧本

## 一、成片定位

- **片名：**《让工厂先在数字世界里运行》
- **品牌：** ForgeMind
- **产品定位：** AI 驱动的智能工厂数字孪生设计与仿真平台
- **建议时长：** 90 秒
- **画幅：** 16:9，4K，24 fps；同时保留 9:16 裁切安全区
- **整体气质：** 近未来工业、克制、精密、可靠；不是赛博朋克废墟，不是夸张的黑客风
- **色彩：** 雾白、浅灰、石墨黑为主；ForgeMind 黄色作为主强调色，辅以青绿色和少量品红 CMYK 印刷色

- **声音：** 低频工业脉冲 + 机械伺服声 + 输送线滚轮声 + 克制的电子合成器；旁白冷静、坚定、略带未来感的中文男声或中性声

## 四、90 秒分镜脚本

### 00:00–00:08｜序章：进入基地

**画面**

全黑。低频电流声响起。黑色工业升降井道中，钢梁、管线和检修灯高速向下掠过，镜头像置身高速上升的轨道舱。画面右下角出现极简等宽读数：`ASCENSION LINK / DECK 041 / 12.8 M/S`。青绿色小指示灯在黑暗中依次点亮。

镜头前方出现白色装甲气密双开舱门，门体有斜切角、铆钉、观察窗和中央锁止结构。舱门上的标识逐渐显现：`FORGEMIND / SECURE TRANSIT`、`A-01`。

**旁白**

> 每一座高效工厂，都从一次准确的进入开始。

**字幕 / 音效**

字幕：`A-01 / DIGITAL FACTORY`。舱门锁止声，随后是厚重的气密门开启声。

**必备特殊元素**

白色气密舱门、黑色升降井道、管线、青绿色指示灯、`A-01`、`ASCENSION LINK`、工业等宽数字。

### 00:08–00:16｜品牌亮相：从现实进入数字孪生

**画面**

舱门打开，外面不是普通厂房，而是一片明亮、干净、带有薄雾的 3D 工厂空间。镜头穿过门槛，地面网格亮起，CAD 十字坐标轴在角落展开。左上角叠加 ForgeMind 徽章与字标，右上角出现：`DIGITAL TWIN / SYNCED`。

镜头缓慢升高，整座单层工厂的设备、输送线和物流通道从网格中逐一被点亮。

**旁白**

> ForgeMind，把工厂的结构、物流、设备与产能，映射到一个可以被看见、被验证、被优化的数字世界。

**字幕**

`ForgeMind`  
`AI-DRIVEN DIGITAL FACTORY`

**必备特殊元素**

原始 FM 徽章、原始 FORGEMIND 字标、黄色斜纹、1 米网格、CAD 坐标轴、白灰工业空间。

### 00:16–00:28｜建造：从空白网格搭起生产线

**画面**

切到 ForgeMind 建造视角。左侧是半透明斜切角设备目录，标签依次闪过：`SOURCE`、`CONVEYOR`、`MACHINE`、`AGV`、`INSPECTION`。操作者拖拽设备到网格中，绿色预览表示合法放置，红色预览表示碰撞冲突；按下 `R`，设备精准旋转 90 度。右键锁定传送带转角，线路像 CAD 草图一样连续生成。

镜头在 3D 视口与界面之间快速切换，展示等距视角、俯视视角和生产流向视角。

**旁白**

> 不需要等待现实施工。先在网格中布置设备，旋转、连接、校验每一个端口，让生产线在落地之前先完成一次推演。

**字幕 / UI 字样**

`02 / BUILD`、`GRID / 1M`、`VALID PLACEMENT`、`FLOW AXIS`、`ROTATE 90°`。

**必备特殊元素**

左侧设备目录、斜切角面板、合法/非法放置颜色、传送带转角、网格、三种视角切换、`R` 和 `ESC` 快捷键。

### 00:28–00:41｜生产链：让物料真正流动起来

**画面**

近景：钢制毛坯从 Source 进入滚筒输送线，金属物料在滚轮之间逐段前进。镜头沿流向穿过传送带，经过加工中心、液压冲压设备和清洗去毛刺单元。加工设备的状态灯由待机变为运行，机械门闭合，主轴与执行机构动作。

切到俯视数字孪生视角，输入端口以青绿色标识，输出端口以黄色标识，箭头将每个设备连接成一条清晰的生产链。右侧面板实时更新：逻辑时间、在途物料、设备利用率、产出数量。

**旁白**

> 从原料，到加工，到输出。每一件物料都有自己的位置，每一台设备都有自己的节拍，每一段输送线都遵循真实的连接关系。

**字幕 / UI 字样**

`SOURCE → CONVEYOR → CNC → WASH / DEBURR → OUTPUT`  
`ITEM LOTS IN TRANSIT`  
`BACKPRESSURE PROTECTED`

**必备特殊元素**

滚筒传送带、移动物料、加工中心、冲压设备、清洗去毛刺设备、输入/输出端口颜色、实时数据面板、背压概念。

### 00:41–00:53｜协同：机器人、AGV 与仓储

**画面**

一只白色 Panda 机械臂在装配单元中完成抓取、定位、装配动作，夹爪闭合时切入微距金属细节。另一处机器人工作站执行分拣 / 焊接 / 装配任务，界面弹出 `ROBOT WORKCELL` 和 `MODE / AUTO`。

镜头拉远，AGV 沿物流通道无声驶过，经过托盘缓存与仓储货架。货物被送入缓存位，安全线和 `AGV LOGISTICS AISLE / KEEP CLEAR` 地面标识从镜头下方掠过。

**旁白**

> 机器人负责动作，AGV 负责流转，仓储负责缓冲。ForgeMind 把每一个环节放进同一张可运行的工厂地图。

**字幕 / UI 字样**

`ROBOT WORKCELL`、`GAMEPAD READY`、`AUTO CYCLE`、`AGV LOGISTICS AISLE`、`BUFFER / READY`。

**必备特殊元素**

Panda 机械臂、白色工业机器人、夹爪、AGV、仓储货架、托盘缓存、安全通道标识、自动 / 手动模式界面。

### 00:53–01:05｜质检：让每个结果都可被验证

**画面**

传送带上的零件进入视觉检测站。检测机械臂末端的摄像头环绕零件移动，画面切换到右侧的 `360° SCAN / 01` 检测窗口：黑色检测底、青绿色取景框、扫描线扫过表面。

**旁白**

**字幕 / UI 字样**

`VISION INSPECTION`、`360° SCAN / 01`、`SCANNING`、`PASS`、`SURFACE CLEAR`。

**必备特殊元素**

检测相机机械臂、检测站传感器、控制柜、黑色相机画面、青绿色取景框、PASS / FAIL 结果、缺陷列表区域。

### 01:05–01:17｜智能管家：用声音读取工厂

**画面**

画面压暗，只留下界面上的数字字节球体。字节 `0 / 1 / ·` 在球体表面缓慢旋转，青绿色与黄色光点组成 BT-7274 的本地智能管家核心。下方出现语音波形。

**字幕 / UI 字样**

`LOCAL INTELLIGENCE / QWEN 2.5`、`BT-7274`、`LISTENING`、`ANALYZING`、`SPEAKING`。

**必备特殊元素**

数字字节球体、语音波形、黄色 / 青绿色脉冲、BT-7274、本地智能、聆听 / 分析 / 播报三态。

### 01:17–01:25｜诊断：让数据变成下一步动作

**画面**

从数字孪生工厂总览快速切换到诊断视角。视口上方显示 `04 / AI FACTORY DIAGNOSTICS`。设备利用率、实时产出、物流负载、生产效率以简洁大数字落入面板；某个传送带末端出现琥珀色提示，镜头沿箭头追踪到瓶颈位置。
