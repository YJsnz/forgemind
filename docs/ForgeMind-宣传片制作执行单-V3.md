# ForgeMind 宣传片制作执行单 V3

关联剧本：[ForgeMind-宣传片剧本-V3.md](ForgeMind-宣传片剧本-V3.md)

## 一、统一视觉提示词

近未来工业软件宣传片，真实工业设备与数字孪生 UI 融合，雾白、浅灰、石墨黑金属，ForgeMind 黄色警示色，青绿色状态灯，细网格、CAD 坐标、切角面板、扫描线、轻微印刷颗粒，镜头克制、稳定、有重量感，4K，16:9，24fps，现代、可靠、精密，不要赛博朋克霓虹，不要废墟，不要人物战斗，不要人形机器人。

所有品牌 Logo、中文和英文 UI 文字均使用项目原始素材或后期合成；视频模型不得自行绘制 Logo 和关键文字。

## 一点五、详细提示词写法

视频模型每个镜头建议单独生成，不要一次生成整支 90 秒片子。每条提示词都明确五件事：

1. **主体：** 工厂、设备、物料、操作员视角或 UI 层。
2. **空间：** A-01、楼层、网格、设备之间的相对关系。
3. **镜头：** 焦段感、机位、运动方向、速度和结束构图。
4. **光线：** 工业顶灯、青绿色状态灯、ForgeMind 黄色警示灯。
5. **稳定性约束：** 不新增设备、不改变传送带方向、不生成可读 Logo、不让物料穿模。

推荐使用“先生成干净画面，再把真实 UI 和文字合成回去”的两阶段流程。生成提示词中的文字只作为构图占位，最终文字必须以后期素材为准。

## 六、后期合成规则

1. 真实项目 UI、Logo、关键文字、状态标签和最终数据必须后期合成或直接录屏。
2. 视频生成模型只负责环境、材质、灯光、设备运动和镜头气氛。
3. 设备、AGV 和物料不得穿透；传送带方向必须与项目真实仿真一致。
4. 不把宣传片表述成已经接管真实工厂的生产控制系统，使用“数字生成、仿真、诊断、决策辅助”的准确表述。
5. 最终输出四个版本：有旁白字幕版、无字幕版、无旁白版、竖屏 9:16 裁切版。

## 七、网络语音与音频素材使用方案

### 可以使用的内容

- 自己录制的声音，或已取得书面授权的配音演员声音。
- MiniMax 官方音色库中允许当前账号和用途使用的系统音色；具体商用范围以当前账号协议和套餐为准。
- 明确标注为 CC0、公共领域或已购买商用授权的音效、音乐和环境声。
- 网络上的公开资料作为旁白事实参考，但旁白文案仍应重新撰写，避免直接复制文章或视频解说。

### 不建议直接使用的内容

- 从影视、游戏、短视频或播客中截取他人声音作为配音素材。
- 未经授权上传主播、演员、游戏角色或公众人物的声音进行克隆。
- 直接下载网络视频中的背景音乐、音效或整段解说，用于对外宣传片。
- 只因为某段音频“在网上能找到”就认定它可以商用。

MiniMax 的官方文档显示，音色复刻需要上传用于复刻的音频；官方指南列出的复刻音频规格为 10 秒至 5 分钟、20MB 以内，示例音频可选且小于 8 秒。声音复刻接口还要求完成个人或企业认证。实际使用时，应同时确认音频本人/权利人的授权，以及 MiniMax 当前服务协议对商业发布的许可范围。

### 本片推荐方案

1. **主旁白：** 使用 MiniMax 官方系统音色，或使用本人/授权配音演员的 10–30 秒干净录音做音色参考。
2. **智能管家：** 使用另一枚有明确授权的中低频系统音色，和主旁白区分，不克隆任何影视或游戏角色。
3. **音乐：** 使用有商用授权的工业电子配乐，或用 MiniMax 音乐生成后保存生成记录、模型版本和授权凭证。
4. **音效：** 使用 CC0/商用音效库，或从项目现有本地音频资产中重新设计，不使用网络影视原声。
5. **发布记录：** 保存音色 ID、来源、授权截图、生成日期、模型版本和最终音频哈希，便于后续证明素材来源。
