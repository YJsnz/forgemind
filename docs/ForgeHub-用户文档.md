# ForgeHub 用户文档

> 版本：2026-09-02 · 当前状态：入口和界面预留

## 1. 模块定位

ForgeHub 是 Forge 生态中的 3D 资产与模型构建入口，目标是让用户管理模型、查看资源说明，并将可复用资产交给 ForgeCloud 和 ForgeMind 使用。

## 2. 当前可用范围

1. 从 ForgeMind 官网顶部导航或官方文档页进入 ForgeHub。
2. 未登录时通过 ForgePass 统一身份入口登录。
3. 登录成功后当前页面展示 ForgeHub 的接口预留状态和产品定位。
4. 正式的模型上传、资产发布、版本管理和社区协作尚未在 ForgeHub 页面开放。

当前不要把 ForgeHub 预览页中的展示图当作已经可下载、可发布或可编辑的资产工作区。需要实际导入 GLB 并在工厂里使用时，请回到 ForgeMind 的“资源导入”流程；需要共享资源说明时，可以在 ForgeLab 发布帖子或附件。

## 3. 未来资产使用建议

准备可复用模型时，建议记录：模型来源、许可证、单位、原点、底面、包围盒、端口方向、适用设备类型和预览图。模型进入 ForgeMind 前仍需经过资源包结构校验和当前用户归属校验。

## 4. 当前边界

- ForgeHub 当前不执行工厂仿真。
- ForgeHub 当前不修改 ForgeMind 存档。
- ForgeHub 当前不提供现场设备控制。
- ForgeHub 正式资产市场、Fork、依赖治理和发布流程以后续实现为准。
