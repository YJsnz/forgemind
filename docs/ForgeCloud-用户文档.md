# ForgeCloud 用户文档

> 版本：2026-09-02 · 适用 ForgeCloud 控制台当前实现

## 1. 模块定位

ForgeCloud 是 Forge 生态的工业智能云控制台，负责工作空间、项目版本、资源、发布、协作、设备摘要、孪生状态、数据事件和 AI 任务的统一管理。

它保存和组织可追溯的云端事实，不替代 ForgeMind 的三维编辑器和逐 tick 仿真，也不直接控制现场设备。

## 2. 登录和工作空间

1. 从 ForgeMind 顶部导航、页脚或直接访问 `/forgecloud`。
2. 未登录时进入 ForgePass，使用已有账户登录或注册。
3. 登录后从左上角工作空间选择器切换空间；管理员可创建工作空间和管理成员。
4. 页面右上角账户菜单可进入成员权限，或执行“退出登录”。

所有云端数据按当前账户和工作空间隔离。没有权限的项目、资源、成员和审计记录不会因为修改浏览器请求而被读取。

## 3. 首页和主要页面

| 页面 | 用户任务 |
| --- | --- |
| 总览 | 查看当前工厂归档、云端资源、连接、数据库状态和活动队列 |
| 项目 | 创建空白项目、提交版本、查看历史和版本评论 |
| 资源 | 登记 JSON/GLB、查看 manifest、创建不可变新版本和下载 |
| 发布 | 将项目版本写入发布记录，查看审批/任务关联 |
| 任务与审批 | 创建任务、发起审批、批准、拒绝或要求重新规划 |
| 设备/孪生/数据 | 登记设备、查看状态、写入手动遥测和查看孪生绑定 |
| 运行与质量 | 查看运行事件、遥测窗口、工单、质量和维护记录 |
| 成员/审计 | 管理非所有者角色、查看活动并导出当前工作空间 CSV |
| AI | 查看规则任务和确定性执行状态 |

## 4. 项目版本

项目版本是不可变记录。进入项目页后创建空白项目，或从 ForgeMind 提交当前存档。提交时系统检查当前版本指纹；如果其他人已经提交新版本，会返回版本冲突，先刷新并重新确认差异。

版本评论、任务和发布记录都绑定到项目版本，不要把“当前工作副本”误认为已经发布的正式版本。

## 5. 资源和许可证

资源可以登记元数据、JSON 定义、GLB 文件和 `manifestVersion=1` 的许可证/依赖信息。公开资源必须有 SPDX、许可证表达式或明确声明；缺少许可证的公开资源会被拒绝。

创建新版本不会覆盖旧版本。资源所有者或工作空间管理员可以创建版本，当前版本切换会保留历史、哈希、文件数量和创建人。

下载或复用资源前，先阅读许可证和来源说明。ForgeCloud 的表格展示的是元数据，不返回数据库凭证，也不直接展示业务表行内容。

## 6. 协作、审批和活动

- 任务和审批都支持客户端幂等键，重复点击不会制造重复业务记录。
- 项目级角色包括 manager、editor、viewer；所有者角色不能被普通成员修改。
- Agent 或移动端产生的请求先进入任务/审批记录，批准后才允许应用受控变更。
- 活动流由审计 Outbox 幂等投影生成；失败事件保留错误摘要并支持重试。

## 7. 工业数据页面

设备页当前用于设备登记、心跳和命令队列摘要；孪生页用于设备与 ForgeMind 对象或外部资产的绑定；数据页用于数据点和手动遥测事件；运行与质量页用于查看已入库的软件事件。

当前页面不会把演示数据、手动遥测或确定性仿真写成真实 OPC UA/MQTT 现场数据。工业连接仍是只读试点，命令默认进入待处理审计队列，不直接驱动设备。

## 8. 常见问题

| 现象 | 处理 |
| --- | --- |
| 看不到项目 | 检查当前工作空间和成员角色 |
| 提交版本冲突 | 刷新项目后基于最新版本重新提交 |
| 公开资源被拒绝 | 补充许可证或改为私有资源 |
| 数据页没有实时值 | 先确认是否有已入库遥测事件 |
| 页面显示 DEMO DATA | 后端不可用，当前是明确标记的本地降级数据 |
