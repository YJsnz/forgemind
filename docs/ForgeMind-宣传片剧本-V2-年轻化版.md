# ForgeMind 宣传片剧本 V2

## 片名

**《MAKE THE FACTORY THINK》**  
中文副标题：**让工厂先在数字世界里运行。**

## 一、创意方向

这不是传统“机器展示片”，而是一支带有任务感的智能制造预告片：年轻操作员进入 A-01 基地，接管一座还没有完全运行的数字工厂，在数字空间中搭建生产链、启动仿真、调度机器人、完成视觉质检，并让本地智能管家给出下一步判断。

整体基调为：**工业软件广告 × 军事科幻任务简报 × 真实制造纪录片**。

艺术方向借鉴以下特征，但不直接复制任何作品的角色、Logo、镜头或 UI：

- 借鉴《明日方舟：终末地》的工业机能秩序：克制的白灰界面、黄色警示线、细网格、切角面板、数据标签、印刷感和工程档案感。
- 借鉴《泰坦陨落 2》的军事科幻临场感：舱门、升降井、操作员视角、机械反馈、任务状态、厚重金属、可靠的军用 AI 通讯质感。
- ForgeMind 自己的核心识别必须保留：FM 工厂徽章、FORGEMIND 字标、黄色斜纹、`A-01` 基地、BT-7274、数字孪生工厂、网格建造、真实生产仿真和本地智能。

## 二、成片参数

- **建议时长：** 100 秒
- **画幅：** 16:9，4K，24 fps；所有关键信息置于中央安全区，方便裁切 9:16
- **镜头节奏：** 前 20 秒建立任务感，中段快速展示能力，后 20 秒完成“运行—诊断—决策”的闭环
- **主色：** 雾白 `#F7F8F6`、浅灰、石墨黑
- **强调色：** ForgeMind 黄 `#E7AD18`；状态青绿 `#459BA0`；通过绿 `#3F9D79`；少量品红 CMYK 印刷色
- **字体气质：** 中文硬朗窄体；英文与数字使用 Doto / 等宽工业字体；UI 文字简短、像任务系统，不堆长句
- **音乐：** 低频脉冲、伺服电机、液压锁止、滚筒输送、无线电静噪；鼓点年轻但不要变成游戏预告片 EDM

## 五、100 秒分镜剧本

### 00:00–00:07｜任务唤醒：A-01 基地在线

**画面**

黑屏。一个青绿色小点亮起，像系统刚刚被唤醒。黑色升降井道中，金属梁、管线、检修灯和电梯轨道高速下掠。画面以 `/public/photos/3.png` 的构图为视觉锚点：白色装甲气密舱门占据中心，右侧深色舰桥认证面板，左侧是 `ASCENSION LINK` 与甲板读数。

画面角落快速出现：

`FM-OS / BRIDGE PROTOCOL 01`  
`ORBITAL LIFT / A-01`  
`DECK 041 / LINK SYNCED`

**无线电式旁白**

> A-01，链路已建立。操作员，准备接管。

**音效**

低频启动、液压锁止、短促的 BT-7274 风格军用通讯提示音。

### 00:07–00:14｜舱门开启：进入数字主甲板

**画面**

认证面板中的身份状态从 `WAITING AUTHORIZATION` 变为 `IDENTITY CONFIRMED`。舱门中央亮起一条青绿色光缝，双门向两侧打开。门外不是普通厂房，而是一片由网格和设备轮廓组成的数字主甲板。

ForgeMind FM 徽章从门缝中央短暂出现，随后贴入左上角。镜头穿过舱门时，现实金属材质转化为干净的 Three.js 数字孪生场景。

**旁白**

> 欢迎来到 ForgeMind。这里，工厂先于现实开始运行。

**必备元素**

白色气密舱门、黑色井道、`IDENTITY CONFIRMED`、FM 徽章、青绿色门缝光、A-01。

### 00:14–00:24｜总览：一座工厂，先被看见

**画面**

用 `/public/photos/1.png` 作为 UI 构图锚点，但让中间 3D 工厂动态化：镜头从等距视角绕过整座单层基地，原料源、传送线、工作站、机器人、缓存、检测站依次点亮。右侧 `FACTORY STATUS / 基地运行舱` 面板同步出现。

底部 KPI 条滑入：

`生产效率`、`设备利用率`、`实时产出`、`物流负载`，并露出 BT-7274 的本地智能球体。

**旁白**

> 不是一张静态布局图，而是一座可以被观察、被运行、被追问的数字工厂。

**镜头语言**

像操作员头盔 HUD 一样，先快速扫过全局，再锁定生产链；运动有惯性，但不要晃动过度。

### 00:24–00:36｜建造：把想法放进网格

**画面**

切换 `02 / BUILD / 工建选址模式`。用 `/public/photos/2.png` 的真实项目截图作为主要 UI 参考：俯视网格、黄色安全线、左下设备目录、右侧状态面板。

操作者从设备目录拖出：

`原料来源` → `原料仓储` → `输送线` → `加工单元` → `机器人装配`。

设备落地时出现合法绿色轮廓；与既有设备重叠时出现红色非法轮廓。按下 `R`，设备精准旋转 90 度；右键锁定传送带转角，线路自动沿网格延伸。

**旁白**

> 先布置，再验证。每个设备、每个端口、每个转角，都在落地之前接受一次检查。

**UI 字样**

`GRID / 1M`、`VALID PLACEMENT`、`ROTATE 90°`、`FLOW AXIS`、`ESC / EXIT BUILD`。

### 00:36–00:47｜定义：物品、配方、生产逻辑

**画面**

界面快速进入 `物品` 与 `配方` 模块。操作员新建一个原料“冷轧钢板”，再建立配方：

`冷轧钢板 ×1 → 机加工壳体 ×1 / 4.0 sec`

镜头切入数据层：物品类型、输入端口、输出端口、加工时长被组织成清晰的工程卡片；随后把配方绑定到数控中心。配方线条变成真实 3D 设备之间的黄色连接线。

**旁白**

> 让一件物品拥有身份，让一条配方拥有节拍，让每一台机器知道自己为什么运行。

**必备元素**

自定义 Item、Recipe、输入/输出数量、加工时长、设备配方绑定、结构化工程数据。

### 00:47–00:59｜仿真启动：物流开始呼吸

**画面**

右侧点击 `启动`。逻辑时间从 `00:00.0` 开始推进，钢板从 Source 出发，沿滚筒传送带逐段移动。微距跟拍物料经过传送带滚轮、转角、加工中心、清洗去毛刺设备，最终变成机加工壳体。

镜头在真实设备细节和数字 UI 之间切换：输入端口以青绿色亮起，输出端口以 ForgeMind 黄色亮起，物料箭头沿连接方向前进。

**旁白**

> 当仿真启动，静态设备变成有节拍的生产系统。每件物料，都有位置；每台机器，都有状态；每条线路，都有方向。

**UI 字样**

`LOGICAL TIME`、`ITEM LOTS IN TRANSIT`、`MACHINE / PROCESSING`、`CONVEYOR / FLOWING`。

### 00:59–01:08｜背压与诊断：系统不会假装顺畅

**画面**

生产链下游短暂拥堵。末端黄色状态灯闪烁，传送带上的物料逐段减速，前方堵塞后上游同步停住。界面出现：`OUTPUT BLOCKED / BACKPRESSURE`。

镜头从一件停下的物料沿生产链反向拉远，所有受影响的段落以琥珀色连锁高亮。随后操作者调整一段传送带位置或增加缓存，重新点击启动，物流恢复。

**旁白**

> 真正的仿真，不会把问题藏在动画背后。堵塞、背压、等待和恢复，都必须被看见。

**必备元素**

背压传播、堵塞状态、上游停机、缓存调整、恢复运行；不要把物料画成穿透设备。

### 01:08–01:18｜协同：机器人、AGV、仓储成为一个系统

**画面**

高速但清晰的三段式蒙太奇：

1. Panda 机械臂闭合夹爪，将零件放入装配夹具；界面显示 `ROBOT WORKCELL / MODE AUTO`。
2. AGV 沿 `AGV LOGISTICS AISLE / KEEP CLEAR` 通道驶过，携带托盘进入缓存区。
3. 仓储货架、托盘缓存、分流器与汇流器在俯视图中组成可追踪的物流网络。

**旁白**

> 机器人执行动作，AGV 负责流转，仓储承担缓冲。复杂的工厂，被组织成一张可以理解的生产网络。

**视觉处理**

保留真实白色工业机器人与黑色/青绿色细节，避免泛化成“未来人形机器人”。

### 01:18–01:29｜质检：360 度看清每一个结果

**画面**

检测站的末端相机围绕零件运动。右侧检测窗口进入 `/public/photos/1.png` 与项目真实 UI 之间的合成状态：

`VISION INSPECTION`  
`360° SCAN / 01`  
`SCANNING`

青绿色扫描线扫过表面，结果先显示 `PASS / 表面无缺陷`。一帧闪切到 `FAIL / DEFECT DETECTED`，缺陷区域出现黄色标记；随后回到合格品通过出口。

**旁白**

> 质量不是最后一张报表。它发生在每一次扫描、每一次判断、每一次放行之中。

### 01:29–01:40｜本地智能：BT-7274 读取工厂

**画面**

底部 KPI 区的 BT-7274 组件放大成画面中心。数字 `0 / 1 / ·` 组成一颗青绿色与黄色交错的字节球体，像一个正在呼吸的本地 AI 核心。

操作者按下语音按钮，状态依次切换：

`聆听中` → `分析中` → `播报中`

旁边的工厂画面实时缩成数据层：设备利用率、实时产出、物流负载、视觉检测结果、当前堵塞点。

**BT-7274 风格播报文案**

> 操作员，A-01 当前运行稳定。检测站已完成质检。物流负载正在上升，建议检查加工单元出口缓存。

**声音说明**

如果拥有合法的 BT-7274 音色授权，可使用授权音色；否则使用“低沉、稳重、可靠、带军用机甲通讯压缩感的中性 AI 音色”，只借鉴功能气质，不直接复制角色原声。

### 01:40–01:50｜宝钗引擎：细节不退让，性能也不退让

**画面**

镜头穿透 3D 工厂，进入半透明技术层：

- 静止 Panda 机械臂合并为共享实例
- 传送带、加工设备、AGV 按批次组织
- 登录舱门打开时，工厂已经在后台预热
- 画面角落短暂出现 `BAOCHAI / RENDER RUNTIME`、`SCENE AUDIT`、`P95 FRAME TIME`

所有技术层线条重新汇聚成真实高精度设备，机械臂动作保持完整，传送带和物料继续运行。

**旁白**

> 细节不应该成为负担。宝钗渲染引擎，让高精度资产、批量设备和实时交互，在同一座工厂里保持流畅。

**注意**

这是 ForgeMind 的技术特色镜头，画面要像“系统内部透视”，不要拍成普通代码雨。

### 01:50–01:58｜诊断：从看见，到决定

**画面**

切换 `04 / DIAGNOSTICS / AI 工厂诊断`。真实项目界面作为锚点，四项指标像任务状态一样快速更新：

`生产效率`、`设备利用率`、`实时产出`、`物流负载`。

操作员切换 `总览`、`生产`、`诊断` 三个视角，瓶颈节点、物流方向和设备状态被同一套数字孪生数据重新解释。

**旁白**

> 先看见变化，再理解原因，最后决定下一步。智能，不是替你猜，而是让每个动作都有依据。
