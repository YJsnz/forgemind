# ForgeMove 用户文档

> 版本：2026-09-02 · 适用原生微信小程序当前实现

## 1. 模块定位

ForgeMove 是面向现场工程师、产线负责人和工厂设计者的移动控制台。它用于快速查看工厂状态、任务、库存、监控、档案和 ForgeLab 社区，不替代 ForgeMind 的三维工作台。

## 2. 打开和登录

1. 使用微信开发者工具导入 `ForgeMove/`。
2. 在 `ForgeMove/config/env.js` 配置 Spring Boot 地址；开发阶段可使用 `http://127.0.0.1:8080`，真机和生产必须使用 HTTPS 合法域名。
3. 点击“进入演示模式”可离线查看完整交互；需要真实数据时使用 ForgePass 账户登录。
4. 在线时小程序会读取认证、工厂、移动摘要、任务和 ForgeLab 接口；接口不可用时显示明确的离线演示标记。

## 3. 页面说明

| 页面 | 用途 |
| --- | --- |
| 工厂总览 | Factory Pulse、工厂状态、同步提示和关键指标 |
| 产线监控 | 查看产线运行摘要和异常状态 |
| 移动任务 | 查看现场任务、维护提醒、审批和待办 |
| 物料库存 | 查看库存、低库存预警、在途数量和来源 |
| ForgeLab 社区 | 浏览动态、求助、经验分享、点赞和草稿 |
| 工厂档案 | 查看项目、楼层、设备、物品和配方摘要 |
| 个人设置 | 查看账户、同步状态、帮助与开源许可 |

## 4. 现场任务

任务页用于确认异常、维护提醒和现场待办。在线时创建或更新的任务会经过后端权限和幂等校验；审批动作会进入统一审批记录。离线时可以先保留待办，但同步前要确认网络恢复和当前项目权限。

## 5. 库存和监控

库存页展示货架、入货仓库、出货仓库和在途摘要。低库存提示用于现场提醒，不会直接修改 ForgeMind 库存。监控页展示移动摘要和最近事件，不等同于三维页面的逐帧坐标或实时仪器读数。

## 6. 离线边界

- 离线演示数据必须以“离线演示”标记识别。
- 小程序不直接连接 MySQL。
- 小程序不执行 Agent Patch。
- 小程序不修改三维布局、碰撞或寻路结果。
- 需要设计、建造、仿真、诊断、审批和资源导入时，返回 ForgeMind Web 工作台。

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| 登录失败 | 检查 API 地址、Spring Boot 8080 和 HTTPS 合法域名 |
| 一直显示离线演示 | 检查网络、API 地址和当前会话是否过期 |
| 看不到工厂 | 确认账号对项目有访问权限 |
| 社区内容不更新 | 下拉刷新并确认 `/api/forgelab/*` 可用 |
