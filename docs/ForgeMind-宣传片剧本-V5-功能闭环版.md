# ForgeMind 宣传片剧本 V5：功能闭环版

## 片名

**《让工厂先运行》**

## 一句话创意

跟随一件电机零件，穿过仓储、加工、跨层物流、机器人装配和视觉质检；当产线出现背压，ForgeMind 在数字世界里找到问题、比较方案，再决定下一步。

## 本版优化方向

V3/V4 的问题是功能点逐个出现，空间和因果关系不够强。V5 只保留一条主线：

```text
L1 原料仓储
  → AGV / 无人机补给
  → L2 四个零件制造岛
  → L3 四路物料汇入机器人装配
  → 视觉质检
  → 合格 / 返工 / 隔离分流
  → 背压诊断
  → A-02 方案生成与副本仿真
  → 应用优化
```

全片只建立一座主工厂空间：A-01。A-02 只在最后作为“重新思考工厂”的实验空间出现。这样每个镜头都服务于同一个生产问题，不再像功能演示合集。

## 成片规格

- **建议时长：** 96 秒
- **建议生成结构：** 8 个空间段，每段约 12 秒
- **若工作流每次只能生成 5 秒：** 每个空间段拆成前 5 秒、后 5 秒，另留 2 秒转场余量；两段继续使用同一空间锚点，不强制首帧尾帧完全一致。
- **画幅：** 16:9，24fps
- **基调：** 近未来工业软件、真实数字孪生、克制、精密、有工程重量
- **主要色彩：** 雾白、浅灰、石墨黑、ForgeMind 黄色、青绿色运行灯
- **核心产品表达：** 设计、运行、观察、诊断、优化

## 统一空间锚点

所有 A-01 镜头必须遵守以下空间关系：

1. **L1 位于最低层：** 左侧为原料仓储和原料货架，中央为 AGV 装卸通道，靠近升降井的位置是无人机停靠点。
2. **L2 位于中层：** 四个制造岛由西向东排列：机加工与清洗、冲压、铜线绕制、紧固件齐套；每个制造岛都有自己的缓存。
3. **L3 位于最高层：** 四条输入支线汇入机器人装配单元，东侧依次是视觉质检、包装、成品缓存和隔离缓存。
4. **主物流方向：** 原料从西侧和下层进入，零件向东侧和上层汇聚，成品从东侧离开。
5. **镜头连续性：** 不改变楼层高度、设备相对位置、输送带方向和安全线颜色；不凭空增加设备，不把工厂变成抽象城市。
6. **主角物料：** 一枚银灰色金属壳体零件，从 L1 原料架开始，到 L2 机加工，再到 L3 装配和质检；它是空间连续性的视觉线索。

## 分镜脚本

### 00:00–00:12｜01 / 工厂先醒来

**画面**

黑色升降井中，A-01 三层工厂的轮廓逐层亮起。镜头沿升降井缓慢下降，经过 L3 的装配层、L2 的制造层，最后落到 L1 原料仓储区。不要急着展示 UI，先让观众理解这是一座有高度、有上下游关系的工厂。

镜头停在 L1 仓储区：左侧原料架，中央 AGV 通道，远处升降井和无人机停靠位。第一件银灰色金属壳体毛坯位于原料架前。

**旁白**

> 一座工厂真正开始生产之前，先要确认的，不是它看起来像不像工厂，而是每一件物料能不能走到该去的地方。

**屏幕后期**

```text
A-01 / DIGITAL FACTORY
THREE FLOORS / ONE PRODUCTION NETWORK
```

**声音**

低频电源启动、升降井钢索、远处风机和仓储区灯光逐级点亮。

**本段目的**

建立全片唯一主空间和主角物料，避免后续镜头看起来像不同工厂。

---

### 00:12–00:24｜02 / 原料进入系统

**画面**

镜头在 L1 仓储区沿 AGV 通道向前推进。AGV 从原料货架取出托盘，驶向线边缓存；银灰色壳体毛坯被送入第一段输送线。镜头跟随托盘，但始终能看到原料架、AGV 通道和升降井之间的关系。

画面右侧出现简洁的物料台账、在途物料和运输状态卡片，但不让生成模型绘制可读文字，统一后期合成。

**旁白**

> 在 ForgeMind 里，仓储不是背景。库存、运输、缓存和在途物料，都是产线能否持续运行的一部分。

**屏幕后期**

```text
RAW MATERIAL / IN TRANSIT
AGV ROUTE / WAREHOUSE → LINE-SIDE
```

**声音**

AGV 电机、托盘轻微碰撞、滚筒启动声，节奏逐渐加快。

**本段目的**

展示项目不是“传送带游戏”，而是包含仓储和厂内物流的生产系统。

---

### 00:24–00:36｜03 / 四个制造岛

**画面**

镜头从 L1 沿升降井切入 L2，但通过同一条垂直结构保持空间连续。镜头在 L2 从西向东平移，依次经过：

1. 机加工与清洗去毛刺；
2. 钢板冲压；
3. 铜线绕制；
4. 紧固件齐套。

主角银灰色壳体进入机加工单元；同时，其他三条物料支线以不同速度运行。每个制造岛都有输入、加工、输出和缓存，不要把它们拍成孤立设备。

**旁白**

> 一件成品，往往不是从一台机器里直接出现。它来自多条节拍不同、方向不同、却必须最终汇合的生产支线。

**屏幕后期**

```text
MACHINING
STAMPING
COIL WINDING
FASTENER KIT
```

**声音**

加工中心门体、冲压短促落下、绕线伺服、物料缓存的机械接触声。

**本段目的**

具体展示电机工艺，而不是泛泛地说“设备协同”。

---

### 00:36–00:48｜04 / 跨层汇合与机器人装配

**画面**

无人机从 L1 停靠位起飞，进入升降井，上升到 L3，再沿高位环线转向装配输入点。镜头从无人机视角下降到 L3，四条输入支线从不同方向汇入机器人装配单元。

机器人依次接收机加工壳体、冲压外壳、铜线圈和紧固件套件。不要表现成机械臂炫技，而要让观众看清“四种输入汇成一个产品”的因果关系。

**旁白**

> 当物料跨越楼层，工厂就不再只是设备的集合。它变成一张包含输送带、AGV、无人机和缓存的生产网络。

**屏幕后期**

```text
L1 → L3
FOUR INPUT LANES
ROBOTIC ASSEMBLY
```

**声音**

无人机升降、旋翼低频、机器人伺服、夹爪闭合、装配完成确认音。

**本段目的**

把多楼层物流与核心产品装配绑定在一起，形成全片视觉高潮。

---

### 00:48–01:00｜05 / 视觉质检与质量分流

**画面**

装配完成的电机进入视觉质检台。白色相机臂沿零件表面做稳定的环绕扫描，青绿色扫描线扫过壳体表面。第一件通过检测，进入包装线；第二件被标记为异常，沿侧向路线进入隔离缓存。

镜头不展示夸张的科幻激光，而是展示相机、检测台、合格路线和隔离路线的空间关系。

**旁白**

> 质量不是最后一张报表。它发生在每一次扫描、每一次判断，以及每一次放行或隔离之中。

**屏幕后期**

```text
VISION INSPECTION
PASS → PACKAGING
FAIL → QUARANTINE
```

**声音**

相机伺服、扫描提示、合格确认音、隔离线路启动声。

**本段目的**

明确视觉检测会改变物流去向，而不是单纯展示一个检测界面。

---

### 01:00–01:12｜06 / 背压暴露瓶颈

**画面**

包装前成品缓存逐渐占满。最前面的物料停止，后方物料依次减速，装配机完成当前周期后停在出料状态，L2 上游缓存也开始积压。黄色警示线沿物流链向上游传播。

镜头沿同一条东向物流路线反向移动，从 L3 的缓存追到装配单元，再追到 L2 制造岛。画面不要爆炸、不要红色灾难警报，用物料速度、设备状态和缓存占用表现背压。

**旁白**

> 真实的产线不会永远顺畅。堵塞、等待和背压，会沿着物流方向反向暴露真正的瓶颈。

**屏幕后期**

```text
OUTPUT BLOCKED
BACKPRESSURE DETECTED
BOTTLENECK / PACKAGING BUFFER
```

**声音**

滚筒逐渐减速、设备负载低频、克制的警示音。不要使用灾难式警报。

**本段目的**

展示 ForgeMind 的核心差异：仿真不仅播放顺畅结果，也能暴露失败原因。

---

### 01:12–01:24｜07 / A-02 重新思考工厂

**画面**

镜头从 A-01 的诊断状态平滑转入 A-02 AI LAB。操作员输入自然语言需求：目标产能、场地大小、设备数量限制和能耗目标。界面依次生成 Recipe Graph、设备估算、端口路由、碰撞校验和三个候选方案。

三个候选方案不是三张随机布局，而是三种策略：保守调整、高吞吐、低能耗。每个方案都显示副本仿真的产能、利用率、能耗、物流效率和回本期。镜头最后落在“SIMULATION VERIFIED / APPLY AFTER REVIEW”。

**旁白**

> ForgeMind 不只告诉你哪里出了问题，还可以把需求变成方案，把方案放进副本里重新运行，再比较哪一种改变真正有效。

**屏幕后期**

```text
RECIPE GRAPH
PORT ROUTING
COLLISION CHECK
TOP 3 CANDIDATES
SIMULATION VERIFIED
```

**声音**

数据节点生成、校验通过、候选方案切换声，音乐重新打开。

**本段目的**

把 AI 从“聊天”升级为可验证的工厂方案生成和调整流程。

---

### 01:24–01:36｜08 / 决策回到工厂

**画面**

镜头回到 A-01。操作员通过本地语音助手询问当前状态。界面显示聆听、分析、播报；智能管家读取真实仿真状态，指出出口缓存负载较高。操作员确认后，应用经过审核的调整方案。

工厂重新运行：缓存压力下降，物流重新流动，合格品进入包装。镜头从 L3 成品缓存拉升到 A-01 三层总览，最后让三层物流线收束为 ForgeMind 黄色斜线，后期叠加 Logo。

**智能管家播报**

> 当前产线运行稳定。包装出口缓存负载较高。建议应用已验证的调整方案。

**旁白**

> 先运行，才能看见问题；看见问题，才有资格做决定。ForgeMind，让工厂先在数字世界里运行。

**屏幕后期**

```text
FORGEMIND
DESIGN · SIMULATE · ANALYZE · OPTIMIZE
```

**声音**

本地 AI 播报、设备恢复运行、音乐收束、干净确认音。

## 表达边界

- 宣传片表达“数字工厂设计、仿真、诊断和决策辅助”，不要表达成已经接管真实工厂 PLC 或生产现场。
- “AI 生成方案”必须和 Recipe Graph、碰撞校验、副本仿真、候选比较一起出现，不要只展示聊天气泡。
- “视觉质检”使用“检测辅助、合格/异常分流”的准确表达，不宣传为未经验证的工业级深度视觉系统。
- 生产效率固定演示读数不作为片中核心指标；优先展示吞吐、在途物料、设备状态、堵塞和候选方案对比。
- Logo、中文、英文、数字、指标和关键 UI 全部使用真实项目录屏或后期合成，视频模型只负责场景、设备、物料和镜头运动。
