# DM4310 六轴桌面机械臂 · 从仿真到真机

ForgeMind 场景中的机械臂（`src/scene/PandaArmModel.tsx`，`panda_joint1..7`）目前是纯仿真。本目录给出用**达妙 DM4310 一体化关节电机**搭建一台 6 自由度桌面机械臂的最小可运行闭环：CAN 协议代码 + 整机装配步骤 + 上电调试流程。目标是电机到手、按本文装完、烧录即通。

## 1. 总体方案

```
220V ─ 24V开关电源(≥350W) ─ 急停开关 ─ XT30并联 ─┬─ DM4310 j1
                                               ├─ ...      （6 颗电机供电）
                                               └─ DM4310 j6
ESP32(GPIO4=TXD, GPIO5=RXD) ─ SN65HVD230 ─ CANH/CANL 菊花链穿过 6 颗电机
        │ USB 串口 115200
        └── PC 串口监视器: list / en / zero / p / demo ...
```

- 每关节一颗 DM4310（内置减速、驱动器、编码器），MIT 运控模式，100Hz 下发 `位置+速度+KP/KD+前馈力矩`。
- 协议层 `dm4310_protocol.h` 平台无关（已在 PC 端单元测试通过），可移植到 STM32 / 树莓派 / USB-CAN。
- 总线层 `dm4310_twai.h` 使用 ESP32 内置 TWAI 控制器 + 廉价收发器模块。

## 3. 出厂检查与上位机设置（关键）

每颗电机先单独用达妙官方「DM 上位机」（配 USB-CAN 或其调试器）确认：

1. **控制模式 = MIT 运控模式**；
2. **CAN 波特率 = 1 Mbps**（本固件固定 1M）；
3. 按下表设置每颗电机的 **CID / MST**；
4. **记录该批电机的 P_MAX / V_MAX / T_MAX**。不同固件批次可能是 `12.5 / 30 / 10`，也可能不同——若与 `dm4310_protocol.h` 中 `range_dm4310()` 不一致，必须改代码后重新编译，否则角度/速度会整体标错。

上电自检：通电时电机「嗒」一声为正常；用手转动输出轴有轻微齿槽阻力感。

## 4. CAN ID 分配表（固件 `CFG[]` 已按此写死）

| 关节 i | 名称 | 机械位置 | CID | MST | 方向 dir | 软限位 | 默认 KP/KD |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 0 | j1_base | 底座旋转 | 0x01 | 0x11 | +1 | ±150° | 30 / 1.5 |
| 1 | j2_shoulder | 肩关节 | 0x02 | 0x12 | +1 | ±100° | 35 / 1.5 |
| 2 | j3_elbow | 肘关节 | 0x03 | 0x13 | −1 | ±130° | 25 / 1.2 |
| 3 | j4_wrist_p | 腕俯仰 | 0x04 | 0x14 | −1 | ±110° | 15 / 0.8 |
| 4 | j5_wrist_r | 腕滚转 | 0x05 | 0x15 | +1 | ±110° | 10 / 0.5 |
| 5 | j6_end | 末端旋转 | 0x06 | 0x16 | +1 | ±90° | 8 / 0.4 |

`dir` 是装配方向：若某关节电机正转时机械臂朝反方向摆，把对应 `dir` 取反即可。KP 单位 N·m/rad、KD 单位 N·m·s/rad（输出轴）。

## 5. 接线

| 连接 | 从 | 到 |
| --- | --- | --- |
| CAN 数据 | ESP32 GPIO4 | HVD230 模块 TXD |
| CAN 数据 | ESP32 GPIO5 | HVD230 模块 RXD |
| 逻辑供电 | ESP32 3V3 / GND | HVD230 3.3V / GND |
| 总线 | HVD230 CANH/CANL | j1 的 CANH/CANL，再跳到 j2…j6 |

要点：

- CAN 全链双绞，**首端和末端各接 120Ω**（测 H-L 电阻约 60Ω 为正确）；
- **全程共地**：电机功率地在电源端单点与逻辑地相连（星形接地），不要让几十安电流流过 CAN 地线；
- 电源线红正黑负，XT30 有防呆但请再核对一次极性，反接烧驱动不可修；
- 急停必须串在 24V 主回路，放在手边。

## 6. 机械装配步骤

参考尺寸（桌面级，末端负载 ≤300g @ 全伸展）：大臂 L1=110mm，小臂 L2=110mm，腕组 L3≈90mm。

1. 下料/打印 6 组关节支架与连杆；DM4310 法兰孔位见达妙图纸（周向 M3）。
2. j1 电机竖装底板中心 → 装底座转盘。
3. j2 电机侧装于 j1 转盘 → 大臂；j3 电机装大臂另一端 → 小臂；j4/j5/j6 依次构成腕三轴。
4. **每装一节手动盘车一圈**，确认无卡滞、无干涉再装下一节。
5. CAN 线沿臂内侧扎带固定，跨关节处留出大于关节行程的松弛段（建议绕关节轴半圈以上的余量），并加应力缓冲。
6. 全部装完后，手动把整臂摆到「零位姿态」：大臂竖直向上、肘部 90°、腕平伸（拍照留存）。此姿态下所有关节角定义为 0°。
7. 末端可换装平行夹爪或吸盘（对应仿真里的 `panda_finger_joint`）。

## 7. 固件烧录

1. 安装 [Arduino IDE](https://www.arduino.cc/en/software)，开发板管理器搜索安装 `esp32`（Espressif 官方核心 ≥2.x）。
2. 打开 `firmware/dm4310_arm_sketch/dm4310_arm_sketch.ino`（无需任何第三方库）。
3. 开发板选 `ESP32 Dev Module`，选对端口，点击上传。
4. 打开串口监视器，波特率 115200，按提示输入命令。

## 8. 上电调试流程（逐步执行）

1. **只接 j1** 到 CAN 总线，上电。
2. 串口输入 `list` → j1 应显示在线且 `err=OK`（离线说明 CID/MST 或接线有误）。
3. 输入 `en 0`（**手扶臂！** 使能后立即有保持力矩）→ `p 0 20` → 应平稳转到 +20°；`p 0 -20` 反向；若方向相反，断电后把 `CFG[0].dir` 改为 `-1` 重烧。
4. `dis` 失能。依次只接 j2…j6 重复 2–3 步验证方向。
5. 全部接回总线，把整臂摆到零位姿态，输入 `zero all` —— 当前位置被存为零点并开始保持。
6. 先降增益试运行：`g 0.5 1` 后 `en all`，观察重力下是否稳定保持；正常后 `g 1 1` 恢复默认增益。
7. `demo` 启动正弦演示，`stop` 停止回零，`dis` 结束。

## 9. 串口命令参考

| 命令 | 作用 |
| --- | --- |
| `help` | 命令列表 |
| `list` | 各关节 目标/角度/角速度/力矩/故障 |
| `en all` / `en <i>` | 使能（使能后保持零位） |
| `dis` | 全臂失能 |
| `zero all` / `zero <i>` | 以当前位置设为零点 |
| `clr` | 广播清除故障 |
| `p <i> <deg>` | 设置目标角（自动夹在软限位内） |
| `g <kp倍率> <kd倍率>` | 全局增益缩放，如 `g 0.5 1` |
| `demo` | 正弦摆动开/关 |
| `stop` | demo 关闭 + 目标全部回零 |

安全机制：任一电机上报非零故障码，固件立即全臂失能并在串口报警。

## 10. 调参指南

- 从小增益起步：底座/肩典型 KP 20–60、KD 1–3；肘 KP 15–40；腕 KP 5–15、KD 0.3–1。
- 抖动/啸叫 → 降 KP 或加 KD；垂头软塌 → 升 KP；持续大电流发热 → 检查结构卡滞。
- 静态重力补偿可用前馈接口：`Joint::command(p, v, kp, kd, tau_ff)` 第 5 参填估算力矩，能显著降低 KP 依赖。

## 11. 故障码表

| 码 | 含义 | 码 | 含义 |
| --- | --- | --- | --- |
| 0x8 | 过压 | 0xC | 电机线圈过温 |
| 0x9 | 欠压 | 0xD | 通讯丢失 |
| 0xA | 过流 | 0xE | 过载 |
| 0xB | MOS 过温 | 0x0 | 正常 |

## 12. 与 ForgeMind 仿真的衔接

- 本机 6 关节命名与场景 `JOINT_NAMES`（`panda_joint1..7`）一一对应（j1–j6），末端夹爪对应 `panda_finger_joint1/2`。
- 后续路线：① 在仿真里录制关节角轨迹导出 JSON，固件加 replay 模式回放；② ESP32 加 Wi-Fi/WebSocket 透传，让 Web 端直接拖动滑块控制真机关节（须另做限位/速度安全层，勿直接透传用户输入）。

## 13. 安全须知

- **首次使能必须手扶或垫托整臂**——失能状态下无保持力矩，使能瞬间重力会让前臂砸落。
- 调试半径内无人无杂物；急停断 24V 主回路，随时可拍。
- 长时间堵转 = 过流过温，闻到异味立即急停。
- 更换机械结构（臂长/负载）后需重调增益与软限位。

## 14. 已知边界（诚实声明）

- 本目录代码**未经真机全流程实测**（当前环境无硬件）：协议数学已通过主机端单元测试（`test/protocol_test.cpp`，g++ 编译运行 ALL PASS）；ESP32 工程未在本机编译，需 Arduino IDE 实际烧录验证。
- `range_dm4310()` 的量程常量以达妙手册常见值为准，**务必用上位机核对你手中批次**。
- 波特率固定 1 Mbps；如你的电机被改过波特率，需同步修改 `TWAI_TIMING_CONFIG_1MBITS()`。
