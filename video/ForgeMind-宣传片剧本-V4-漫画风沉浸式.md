# 一、核心创意

这不是产品演示，是一段"进入数字世界的体验"。

**开场**：黑屏，一枚青绿色光点唤醒，一个漫画分格边框从屏幕外滑入、在你面前展开——你走进去，站在一座还没建成的数字工厂里。

**过程**：你以第一人称站在一座还没建成的数字工厂里，亲手做完全程——

> **BUILD**（在网格里搭起产线）
> **RUN**（让仿真真正跑起来，物料流动、背压真实暴露）
> **FIND**（系统告诉你问题出在哪）
> **FIX**（在数字世界里改，不改现实）
> **THINK**（本地 AI 帮你分析、决定）

**收尾**：漫画世界收束成一条黄色工程线，硬切黑屏，ForgeMind 品牌定格。

观众看完只记住一句话：

> **原来，我可以在工厂真正落地以前，就知道它会怎么运行。**

# 二、视觉风格：蜘蛛侠纵横宇宙 × ForgeMind 工厂

## 2.1 风格定位：漫画 × 写实混合

**默认世界 = 蜘蛛侠纵横宇宙漫画风**（数字孪生世界的语言）：图形化、有能量、年轻、够酷。

**高光瞬间 = 写实高保真**（证明产品真实性的时刻）：当镜头必须让人相信"这是真的"，风格瞬间 punch 到写实。

> 主题装置：**漫画世界 = 数字孪生；写实瞬间 = 仿真真实到以假乱真。** 数字变成现实的那一刻，是全片最酷的高光。

- 工厂内容保持 ForgeMind 真实特征：滚筒输送带、白色工业设备、机械臂、AGV、仓储、网格地面、视觉检测相机
- 明亮、干净、有能量——不是暗黑工业风

## 2.2 漫画风要素（"酷"点）

| 要素 | 用法 |
|---|---|
| 粗黑描边 | 所有设备、工件轮廓 |
| 网点半调 | 背景阴影、渐变 |
| 撞色 | ForgeMind 黄 × 青绿为主，黑/白/灰打底 |
| 动态构图 | 低角度仰视、荷兰角、大胆负空间、斜切画面 |
| 速度线 + 爆发框 | 运动、启动、故障、恢复 |
| 漫画分格 | 转场、蒙太奇、双线叙事 |
| 拟声字（后期） | `CLACK` `BOOM` `VROOM` `SNAP` |
| 手绘纹理 | 纸张颗粒、墨线 |

## 2.3 写实高光（"可信"点，写实为主 + 漫画点缀）

| 要素 | 用法 |
|---|---|
| 真实金属材质 | 零件表面、加工纹理 |
| 真实工业照明 | 干净、有层次，不做暗黑 |
| 浅景深 | 微距跟拍、检测特写 |
| 真实物理尺度 | 设备比例、运动速度符合现实 |
| 高级产品广告摄影 | 克制、精确、可靠 |

**写实为主，叠加漫画元素丰富画面**：网点半调阴影、黄色漫画速度线与爆发框、漫画分格边框——让写实画面也有漫画的年轻感，像《蜘蛛侠纵横宇宙》里立体角色身上的漫画笔触。

## 2.4 色彩体系（漫画化）

- 底：雾白 `#F7F8F6`、漫画白、石墨黑 `#1F2422`

**写实为主（约 60%）**——真实机械、高精度工厂，证明产品真实；**漫画为创意层（约 40%）**——数字 UI、建造、入口、AI 人格。

# 三、声音体系

## 3.1 声音原则

整片 AI 就是旁白者——观众在"听一套已经上线的智能系统汇报工厂状态"。

## 3.2 声线设定（BT-7274 气质）

- 男性，30–45 岁听感，低音区，胸腔共鸣明显
- 情绪波动极小，语速约 0.85–0.92×
- 辅音清楚、句尾干净、可靠稳定克制
- 轻微无线电压缩 + 少量窄带通信质感 + 极轻机械谐波
- 不做夸张机器人变声
- 无授权则用功能型声线，不 1:1 克隆原角色

## 3.3 音乐方向

- 年轻、有能量，但保持"工业感"
- 参考：Industrial Breakbeat × Minimal Techno × 机械打击乐（约 110–124 BPM）
- 关键节奏点（设备落下、堵车、恢复）全部卡拍

# 四、沉浸式原则

1. **第一人称 POV**：观众=操作员，站在网格上、跟着物料走、看着 AI 说话
2. **漫画分格是门**：分格不只是剪辑，是通往漫画世界的门——你穿过它，走进工厂
3. **设备在周围"活"**：镜头贴近机械臂/输送带/AGV，有临场重量感
4. **AI 直接对你说**：旁白=AI 在你耳边汇报，不是广告配音
5. **不跳脱**：全片停留在"漫画数字工厂"这一世界观，真实 UI 截图作为"系统面板"嵌入漫画分格（后期合成）

# 六、H3 生成原则

1. **一镜头一个主体动作**：只让一件事发生（机械臂抓取 / 物料前进 / 设备落下 / 相机扫描）
2. **统一漫画风格后缀**（见第十节），所有 AI 镜头追加
3. **无文字、无 Logo、无复杂 HUD**——统一后期叠加
4. **主色控制**：黄 `#E7AD18` + 青绿 `#459BA0` + 雾白/石墨黑
5. **素材数量**：约 18–22 条 AI 素材，每条 4–7 秒，实拍用 1–5 秒
6. **稳定性优先**：宁可简单正确，不要炫但错误
