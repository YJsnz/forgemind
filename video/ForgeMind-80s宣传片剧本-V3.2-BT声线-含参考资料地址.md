> **成片时长：80 秒**  
> **项目：FORGEMIND — SMART MANUFACTURING PLATFORM**  
> **核心定位：数字孪生 × 工业仿真 × 智能诊断 × 本地 AI**  
> **声音人格：BT-7274 气质的低沉、可靠、战术型 AI 声线**

---

# 一、宣传片核心创意

这不是一支“逐项介绍 ForgeMind 功能”的产品演示片。

整支片只回答一个问题：

> **如果一座工厂，可以在真正建成之前，先运行一次呢？**

ForgeMind 的价值不再通过“功能清单”解释，而是通过一个完整过程自然呈现：

**BUILD → RUN → FIND → FIX → THINK**

即：

**构建工厂 → 运行工厂 → 暴露问题 → 调整方案 → 智能决策**

观众看完 80 秒后，只需要记住一句话：

> **原来，我可以在工厂真正落地以前，就知道它会怎么运行。**

# 三、声音体系

## 3.1 核心原则

整片尽量取消传统“广告解说员”。

ForgeMind 的 AI 本身就是旁白者。

观众不是在“听别人介绍 ForgeMind”，而是在听一套已经上线的工业智能系统主动汇报工厂状态。

声音感觉：

> **像一个极其可靠、冷静、一直站在操作员身边的智能机甲伙伴。**

---

## 3.2 声线设定

如果拥有 BT-7274 原声或相关音色的合法授权，可直接使用授权声线。

如果没有授权，建议制作一套具有相近功能气质、但不进行 1:1 模仿的 ForgeMind 专属 AI 声线：

- 男性
- 30–45 岁听感
- 低音区
- 胸腔共鸣明显
- 情绪波动极小
- 语速约 0.85–0.92×
- 辅音清楚
- 句尾干净
- 可靠、稳定、克制
- 轻微无线电压缩
- 少量窄带通信质感
- 极轻机械谐波
- 不做夸张机器人变声

声音关键词：

**LOW / CALM / RELIABLE / TACTICAL / MACHINE-COMMS / TRUSTWORTHY**

# 四、H3 Lite 生成总原则

由于本地模型能力有限，必须优先保证稳定性。

## 4.1 一镜头一个主体动作

错误：

> AGV 行驶，同时机械臂抓取，同时输送带运行，同时 UI 弹窗，同时镜头环绕。

正确：

> 镜头低角度跟随一个金属工件沿输送带稳定前进。

---

## 4.2 AI 不负责生成复杂文字

以下内容统一后期叠加：

- FORGEMIND
- A-01
- BUILD
- RUN
- FIND
- PASS
- OUTPUT BLOCKED
- UI 数值
- Logo
- 中文
- 英文标题

AI 镜头中尽量：

> **无文字、无 Logo、无复杂 HUD。**

---

## 4.3 Logo 必须使用原始素材

使用：

- `logo_image.png`
- `logo_zimu.png`

禁止 AI：

- 重绘 Logo
- 修改 Logo
- 生成相似 Logo
- 3D 扭曲 Logo
- 霓虹描边 Logo
- 随机拼写 FORGEMIND

---

## 4.4 真实 UI 直接录屏

ForgeMind 的真实界面必须保留。

推荐比例：

- 真实 ForgeMind UI：约 30%
- AI 工业电影镜头：约 50%
- 品牌图形 / 字幕 / Logo：约 20%
